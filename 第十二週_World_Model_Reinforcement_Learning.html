1. 為什麼要學 World Model？—— Model-Based RL 的動機

在傳統強化學習（Model-Free RL，例如 PPO、SAC、DQN）中，智能體必須透過與真實環境（或模擬器）反覆互動， 才能學到「在狀態 \(s\) 下採取動作 \(a\) 能得到多少報酬」。這種學習方式的樣本效率（sample efficiency）通常很差： 每一次梯度更新都仰賴新的環境互動資料，對於高維度像素輸入、動力學複雜、渲染成本高的任務（例如無人機競速）而言， 訓練成本會非常昂貴。

Model-Based RL（MBRL） 的核心想法，是先學一個「世界模型」（World Model）—— 一個能夠預測環境動態的神經網路， 再讓智能體在這個學到的模型裡「想像」（imagine）大量的虛擬軌跡來訓練 actor 與 critic，而不必每一步都真的去環境裡跑。 這個想法最早可以追溯到 Sutton 的 Dyna 架構、Ha & Schmidhuber 2018 年的 World Models 論文（見第 1.5 節）， 而 Dreamer 系列演算法（Hafner et al.）則是把這個想法發展成一套可以在超過 150 種不同任務上、 用同一組超參數穩定運作的通用演算法。

定義 1.1　世界模型（World Model）

給定觀測序列 \(x_{1:T}\)、動作序列 \(a_{1:T}\)，世界模型學習一個潛在狀態轉移模型：

\[ p_\phi(z_t \mid h_t), \qquad h_t = f_\phi(h_{t-1}, z_{t-1}, a_{t-1}) \]

其中 \(z_t\) 為隨機潛在表徵（stochastic latent），\(h_t\) 為遞迴狀態（deterministic recurrent state）。 兩者合併 \(s_t \doteq \{h_t, z_t\}\) 構成完整的模型狀態（model state）， 之後的 reward、value、action 都是在這個壓縮後的潛在空間中被預測與學習，而不是直接對高維像素操作。

為什麼不直接對像素做 RL？ 因為原始影像維度極高（例如 \(64\times64\times3\)），Model-Free RL 需要極大量互動樣本才能學出好的策略， 且梯度訊號稀疏、雜訊大。World Model 先把「感知」與「決策」解耦： encoder 負責把像素壓成資訊量足夠但維度低的潛在向量，決策（actor-critic）則完全在這個潛在空間中進行， 大幅降低了樣本複雜度，這也是 Dreamer 系列論文反覆驗證的核心優勢。

World ModelV-M-C 架構 定位：本教材前述五篇 Dreamer 系列論文的直接精神起源。首次以簡潔的 「視覺（V）— 記憶（M）— 控制器（C）」三元件架構，示範如何把一個高維視覺控制任務拆解成 「先無監督學習世界模型、再用極小的控制器學習決策」，並且證明 agent 可以完全在自己世界模型產生的「夢境」中訓練， 再把學到的策略遷移回真實環境。這篇論文比 DreamerV1（2019）早了將近兩年，是理解「為什麼要把感知與決策解耦」 「為什麼可以在想像中訓練」這兩個 Dreamer 系列核心概念最好的起點。

1.5.1　動機：人腦中的「心智模型」

論文開場引用系統動力學之父 Jay Wright Forrester 的話：「我們腦海中攜帶的世界圖像，只是一個模型。 沒有人的腦中會想像出整個世界、整個政府或整個國家；他只選取了一些概念與它們之間的關係，用來代表真實系統。」 Ha & Schmidhuber 從棒球打者只有數十毫秒反應時間卻能揮棒擊中 100 mph 速球的例子出發， 主張人類是靠大腦內建的預測模型做出反射性動作，而非即時對每個可能的未來展開規劃 —— 這正是「World Model」一詞在此文中的核心隱喻：先學會預測，再用預測結果做決策，而不必每次都重新規劃。

1.5.2　V-M-C 三元件架構

論文提出一個受認知系統啟發的簡單 agent 模型，包含三個各司其職、分開訓練的組件：

V（Vision）：VAE 視覺模型

用一個標準的變分自編碼器（VAE）把每個影格 \(64\times64\times3\) 的像素觀測壓縮成低維潛在向量 \(z\) （CarRacing 取 \(N_z=32\)，Doom 取 \(N_z=64\)），訓練目標為重建誤差（\(L^2\)）加上 KL 正則項。 V 的角色僅止於「空間壓縮」，完全不涉及時間或決策資訊。

M（Memory）：MDN-RNN 記憶模型

一個 LSTM 搭配混合密度網路（Mixture Density Network）輸出層，學習預測下一時刻潛在向量的機率分佈：

\[ P(z_{t+1}\mid a_t, z_t, h_t) \]

其中 \(h_t\) 為 LSTM 隱藏狀態，\(a_t\) 為採取的動作。輸出為多個高斯分佈的混合，並可用溫度參數 \(\tau\) 在取樣時調整不確定性。這正是「時間壓縮」——把「環境如何隨時間演化」也壓縮進一個可微分的遞迴模型中。

C（Controller）：刻意做到極簡的線性控制器

Controller 是一個單層線性模型，直接把 \(z_t\) 與 \(h_t\) 串接後映射到動作：

\[ a_t = W_c\,[z_t\;h_t] + b_c \]

作者刻意讓 C 盡可能小、盡可能簡單——CarRacing 任務中 C 僅有 867 個參數， 相對於 VAE 的 4,348,547 個與 MDN-RNN 的 422,368 個參數而言微不足道。 這個設計哲學是本文最重要的洞見之一：把模型的「容量」與「表達力」都留給 V 和 M， 而把強化學習演算法真正要解決的「信度分配問題」（credit assignment）限縮在一個極小的搜尋空間裡， 如此一來即使使用樣本效率較差、但不需要梯度、且易於平行化的演化策略（Evolution Strategies） 也能有效訓練 C。

三者串接後的推論迴圈可以用一段偽代碼精確描述（原論文 Algorithm，OpenAI Gym 介面）： 

def rollout(controller):
    obs = env.reset()
    h = rnn.initial_state()
    done = False
    cumulative_reward = 0
    while not done:
        z = vae.encode(obs)                  # V：壓縮觀測
        a = controller.action([z, h])        # C：決策
        obs, reward, done = env.step(a)
        cumulative_reward += reward
        h = rnn.forward([a, z, h])           # M：更新記憶狀態
    return cumulative_reward

1.5.3　訓練方式：CMA-ES 演化策略，而非梯度反傳

與後續 Dreamer 系列用解析梯度反傳或 REINFORCE 訓練 actor 不同， 本文使用 Covariance-Matrix Adaptation Evolution Strategy（CMA-ES） 這種無梯度的黑箱優化演算法來演化 C 的權重： 族群大小 64，每個個體在環境中跑 16 次不同亂數種子取平均累積報酬作為適應度（fitness）。 這件事之所以可行，正是因為 C 的參數量極小（867 個）——CMA-ES 適合求解至多幾千維的解空間， 若要直接演化整個端到端網路（V+M+C 共約 470 萬參數）則完全不切實際。

1.5.4　CarRacing-v0 實驗：V 與 M 的貢獻分離驗證

作者做了一個很有教學意義的消融實驗：先只讓 C 存取 \(z_t\)（不含 \(h_t\)）， 觀察到 agent 雖能沿賽道行駛，但在急彎處會搖擺不穩；再讓 C 同時存取 \(z_t\) 與 \(h_t\)，操控明顯更穩定。 這證明了 \(z_t\) 只捕捉「當下瞬間」的空間資訊，而 \(h_t\)（M 對未來的預測狀態）才提供了「對未來的期待」， 兩者合併才能讓控制器做出反射性、不需要顯式規劃的決策 —— 與 1.5.1 節棒球打者的類比前後呼應。

1.5.5　「在夢境中訓練」：VizDoom Take Cover 實驗

本文最具啟發性的貢獻，是證明 agent 可以完全不碰真實環境、只在 M 產生的「幻覺」環境中訓練策略， 再把學到的策略部署回真實環境。要做到這件事，M 除了預測 \(z_{t+1}\)，還需額外預測一個二元的 結束狀態 \(d_{t+1}\)（agent 是否已死亡）：

\[ P(z_{t+1},\,d_{t+1}\mid a_t,\,z_t,\,h_t) \]

有了 \(d_{t+1}\)，M 就具備了完整 RL 環境所需的全部要素（下一狀態 + 結束訊號）， 於是可以把 M 包裝成一個標準 gym.Env 介面，讓 agent 完全在這個「潛在空間虛擬環境」（論文稱之為 DoomRNN）中用 CMA-ES 訓練 C，全程不需要 V 解碼任何真實像素，也不需要真的跑 Doom 遊戲引擎。 訓練出的策略部署回真實 VizDoom 環境後，存活時間達到 \(1092 \pm 556\) 個時間步，遠超過解出此任務所需的 750 步門檻。

「作弊」世界模型：agent 找到 M 的漏洞

由於 M 只是環境的近似機率模型，agent 在演化過程中會找到「在真實環境中不存在、但在 M 的想像中有效」 的對抗性策略——例如作者觀察到某些 agent 學會用一種奇特的移動方式，讓 M 想像出的怪物「從不發射火球」， 即使已經出現火球形成的徵兆，agent 仍能像擁有超能力一樣讓火球「憑空消失」。這類策略在虛擬環境中得分完美， 但部署回真實環境立刻失敗，表現甚至不如隨機策略。

論文用溫度參數 \(\tau\) 系統性地量化了這個「現實 vs. 可利用性」的取捨：

溫度 \(\tau\)虛擬環境分數真實環境分數
0.10（近乎確定性）\(2086 \pm 140\)\(193 \pm 58\)
0.50\(2060 \pm 277\)\(196 \pm 50\)
1.00\(1145 \pm 690\)\(868 \pm 511\)
1.15\(918 \pm 546\)\(1092 \pm 556\)
1.30\(732 \pm 269\)\(753 \pm 139\)

溫度太低（\(\tau=0.1\)）時 M 幾乎退化成確定性 LSTM，混合密度模型發生「模式崩塌」（mode collapse）—— 怪物永遠不會進入「射擊」這個機率模式，agent 在夢境中可以拿到接近滿分的 2100 分， 但部署到真實環境立刻崩潰。適度提高溫度（\(\tau\approx1.15\)）反而讓虛擬環境分數下降， 卻讓真實環境的遷移表現達到最佳——這是一個重要的教學案例：世界模型的「不確定性」本身可以是一種正則化， 用來對抗控制器對模型缺陷的過度利用。

1.5.6　與後續 Dreamer 系列的關係：這篇論文「留下的伏筆」

本文明確指出、後來被 Dreamer 系列逐一解決的侷限

  • V/M/C 完全分開訓練——V 是無監督訓練，不知道任務目標是什麼，因此可能學到「與任務無關」的細節 （論文舉例：VAE 精細重建了 Doom 場景牆上不重要的磚紋，卻無法在 CarRacing 中重建賽道邊緣的重要標線）。 DreamerV1 之後選擇讓世界模型與 reward 預測聯合訓練，讓表徵學習偏向任務相關特徵，正是針對此侷限的直接回應。
  • C 只用演化策略、不做梯度反傳穿過 M——論文在 Discussion 中明白寫道：「因為我們把世界模型實作成完全可微分的遞迴計算圖， 原則上我們或許能夠直接用反向傳播演算法在夢境中訓練 agent，微調其策略以最大化目標函數。」 這句話幾乎是在預言 DreamerV1 的解析梯度反傳（analytic value gradients）方法。
  • M 是「隨機模型但非時序上的層級式規劃」——論文承認其方法「像早期的 C–M 系統一樣，逐時間步一步步模擬可能的未來， 並未享受到人類式的階層規劃或抽象推理的好處」，並援引 Schmidhuber 的 Learning to Think （2015a）框架指出更一般化的可能性—— 這條研究路線後續由 DreamerV2/V3 的離散潛在表徵與更長的想像視野（imagination horizon）部分實現。
  • 世界模型容量有限、會發生災難性遺忘——本文使用的是相對小型的 LSTM，論文明確指出「人腦可以保存數十年甚至數世紀解析度的記憶， 而我們用反向傳播訓練的神經網路容量有限，且會遭遇災難性遺忘問題」，並列為未來工作方向。 DreamerV3 的 symlog/symexp 正規化與更大規模的世界模型，可視為對此問題的一種延遲回應。
教學重點：為什麼要先讀這篇 2018 年的論文，才讀 Dreamer？ 因為 Dreamer 系列的每一個「創新」，幾乎都可以在這篇論文的 Discussion 段落中找到「作者自己指出的侷限」作為對照組。 把兩者放在一起讀，可以清楚看出一條「一個侷限被下一代方法解決」的技術演進鏈，而不是把 RSSM、KL balancing、 symlog 等技巧當成憑空出現的黑盒子技巧。此外，V-M-C 這個「感知—記憶—決策」三分法的直覺框架， 至今仍是理解任何 model-based RL 架構最快的心智模型（mental model）——這也恰好呼應了論文開頭引用 Forrester 的那句話。

3. DreamerV1：Dream to Control（潛在想像的起點）

3.1　問題設定：POMDP 與三個核心分佈

DreamerV1 把視覺控制問題形式化為部分可觀測 MDP（POMDP）：離散時間步 \(t\in[1,T]\)， 動作 \(a_t\sim p(a_t\mid o_{\le t},a_{

其潛在動態模型（latent dynamics）由三個組件構成，這是後續 RSSM 家族的雛形：

\[ \text{Representation model: } p(s_t\mid s_{t-1},a_{t-1},o_t) \qquad \text{Transition model: } q(s_t\mid s_{t-1},a_{t-1}) \qquad \text{Reward model: } q(r_t\mid s_t) \]

論文用 \(p\) 表示「會產生真實環境樣本」的分佈，\(q\) 表示「用於潛在想像」的近似分佈。 關鍵在於 transition model：它完全不依賴當前觀測 \(o_t\)，只從前一步的模型狀態與動作預測下一狀態， 這使得 agent 可以在完全不生成/觀察影像的情況下，於潛在空間中平行想像成千上萬條軌跡， 記憶體佔用極小、速度極快 —— 這正是「world model 支撐大量離線想像訓練」概念最早的完整實現。

3.2　核心貢獻：用解析梯度學習長時程行為

DreamerV1 定義了一個「想像 MDP」：從真實經驗中取樣出的模型狀態 \(s_t\) 出發， 之後的軌跡完全由學到的模型生成：

\[ s_\tau \sim q(s_\tau\mid s_{\tau-1},a_{\tau-1}), \qquad r_\tau \sim q(r_\tau\mid s_\tau), \qquad a_\tau \sim q(a_\tau\mid s_\tau) \]

目標是最大化想像報酬的期望：\(\mathbb E_q\big[\sum_{\tau=t}^{\infty}\gamma^{\tau-t}r_\tau\big]\)。

Action model 與 Value model 分別為：

\[ \text{Action model: } a_\tau\sim q_\phi(a_\tau\mid s_\tau) \qquad \text{Value model: } v_\psi(s_\tau)\approx \mathbb E_{q(\cdot\mid s_\tau)}\Big[\sum_{\tau=t}^{t+H}\gamma^{\tau-t}r_\tau\Big] \]

Action model 輸出 tanh 變換過的高斯分佈，並用重參數化技巧（reparameterization）取樣， 使動作可視為神經網路輸出的確定性函數：

\[ a_\tau = \tanh\big(\mu_\phi(s_\tau) + \sigma_\phi(s_\tau)\,\epsilon\big), \qquad \epsilon\sim \mathcal N(0,\mathbb I) \]

DreamerV1 最大的特色：解析梯度反傳（Analytic Value Gradients）

因為 transition/reward/action/value 全部都是可微分的神經網路，價值估計 \(V_\lambda(s_\tau)\) 對 action model 參數 \(\phi\) 的梯度可以直接解析計算，不需要像 policy-gradient 方法 （A3C、PPO）那樣依賴高方差的 REINFORCE 估計器：

\[ \nabla_\phi\, \mathbb E_{q_\theta,q_\phi}\Big(\sum_{\tau=t}^{t+H}V_\lambda(s_\tau)\Big) \]

這種「透過學到的動態模型反傳解析梯度」的作法，與 DDPG/SAC 等 deterministic actor-critic 方法精神相通， 但 DreamerV1 進一步把梯度穿過多步的想像動態，而非僅止於單步 Q 值，因此能更有效率地學習長時程行為。

3.3　價值估計：\(V_R\)、\(V_N^k\)、\(V_\lambda\) 三種估計子

給定有限想像視野 \(H\)，狀態價值可用三種方式估計，在偏差與方差間取捨：

\[ V_R(s_\tau) \doteq \mathbb E_{q_\theta,q_\phi}\Big(\sum_{n=\tau}^{t+H}r_n\Big) \]

\[ V_N^k(s_\tau) \doteq \mathbb E_{q_\theta,q_\phi}\Big(\sum_{n=\tau}^{h-1}\gamma^{n-\tau}r_n + \gamma^{h-\tau}v_\psi(s_h)\Big), \quad h=\min(\tau+k,\,t+H) \]

\[ V_\lambda(s_\tau) \doteq (1-\lambda)\sum_{n=1}^{H-1}\lambda^{n-1}V_N^n(s_\tau) + \lambda^{H-1}V_N^H(s_\tau) \]

\(V_R\) 直接加總視野內報酬、忽略視野外的一切——這樣完全不需要 value model， 但代價是視野外的長期收益被完全捨棄，導致「短視」行為。\(V_N^k\) 用學到的 value model 估計 \(k\) 步之後的價值， \(V_\lambda\) 則是不同 \(k\) 的指數加權平均，是 DreamerV1 實際採用的估計子。

關鍵實驗：為什麼一定要學 Value Model？

論文比較了「Dreamer（用 \(V_\lambda\)）」、「No value（只用 \(V_R\)，不學 value model）」、 與「PlaNet（線上規劃、也只用 \(V_R\)）」在不同想像視野 \(H\in\{10,20,30,40\}\) 下的最終表現（Fig. 4）。 結果顯示：只要學了 value model，Dreamer 對想像視野長度幾乎不敏感——即使 \(H=10\) 也能維持高分； 而不學 value model 的兩種方法則表現隨視野縮短而急遽下滑，證明了「用 value model 估計視野外報酬」 是解決短視問題的關鍵設計。

3.4　世界模型的三種學習目標（Representation Learning）

DreamerV1 系統性比較了三種訓練 world model 的方式，這是與後續版本銜接的重要基礎：

方法核心公式特點
影像重建（Reconstruction，沿用 PlaNet） \(\mathcal J_{\text{REC}}\doteq\mathbb E_p\Big(\sum_t \mathcal J_O^t+\mathcal J_R^t+\mathcal J_D^t\Big)\)， 其中 \(\mathcal J_D^t \doteq -\beta\,\mathrm{KL}\big[p(s_t\mid s_{t-1},a_{t-1},o_t)\,\|\,q(s_t\mid s_{t-1},a_{t-1})\big]\) 本質是變分下界（ELBO/VIB），表現最佳，是 DreamerV1 預設方法
對比估計（Contrastive / NCE） \(\mathcal J_S^t \doteq \ln q(s_t\mid o_t) - \ln\sum_{o'}q(s_t\mid o')\) 不必重建像素、只需讓狀態可從影像預測且保持多樣性，效果約解決半數任務
純報酬預測（Reward prediction） 僅用 \(q(r_t\mid s_t)\) 提供學習訊號 實驗中不足以學到有用表徵，尤其在報酬稀疏時

這個消融結果（Fig. 8）直接啟發了後續 DreamerV2／V3 都預設採用「影像重建」作為表徵學習目標， 但也保留了「重建目標可以替換」的彈性設計精神。

4. DreamerV2：離散世界模型與 Atari 人類水準

4.1　核心改變：類別潛在表徵取代高斯分佈

DreamerV2 的世界模型延續 RSSM 架構，但把隨機潛在狀態從 DreamerV1／PlaNet 的對角高斯分佈 改為一組類別分佈（32 個類別變數、每個 32 類），這是 DreamerV2 相對 V1 最關鍵的架構改變：

\[ \text{RSSM} \begin{cases} \text{Recurrent model: } & h_t = f_\phi(h_{t-1},z_{t-1},a_{t-1})\\ \text{Representation model（後驗）: } & z_t \sim q_\phi(z_t\mid h_t,x_t)\\ \text{Transition predictor（先驗）: } & \hat z_t \sim p_\phi(\hat z_t\mid h_t)\\ \text{Image predictor: } & \hat x_t \sim p_\phi(\hat x_t\mid h_t,z_t)\\ \text{Reward predictor: } & \hat r_t \sim p_\phi(\hat r_t\mid h_t,z_t)\\ \text{Discount predictor: } & \hat\gamma_t \sim p_\phi(\hat\gamma_t\mid h_t,z_t) \end{cases} \]

注意此處的符號慣例與 DreamerV3（見第 5 節）已幾乎一致——事實上 DreamerV3 的 RSSM 命名與結構 就是直接沿用 DreamerV2 這裡定義的「Recurrent model / Representation model（後驗）/ Transition predictor（先驗）」 三件式架構，只是 DreamerV3 額外加上了 1% unimix 與 free bits。

為什麼類別分佈比高斯分佈更適合？（論文提出的四個假說）

  • 先驗更容易擬合後驗：類別分佈的混合仍是類別分佈，先驗 \(p_\phi(\hat z_t\mid h_t)\) 原則上可以完美匹配後驗的混合分佈；而高斯先驗無法精確匹配高斯混合，難以表達「下一幀可能是好幾種不同結果之一」的多模態變化（例如轉角後可能出現的不同場景）。
  • 稀疏性有利泛化：32 個類別變數各取 32 類中的 1 類，展平後得到長度 1024、僅 32 個位元為 1 的稀疏二元向量，這種稀疏表徵可能有助於類似 dropout 的正則化效果。
  • Straight-through 梯度可能更好優化：不像重參數化梯度會保留一個可能導致梯度爆炸/消失的縮放項，straight-through 估計器結構更簡單。
  • 類別變數可能是更好的歸納偏差：適合表達 Atari 遊戲中「非平滑」的變化，例如進入新房間、道具/敵人消失等離散事件，比單峰連續分佈更自然。

4.2　Straight-Through 梯度：如何對「取樣」這個不可微分操作反傳梯度

由於類別分佈的取樣（\(\mathrm{argmax}\) 或 one-hot 抽樣）本身不可微分，DreamerV2 採用 straight-through 估計器：

sample = one_hot(draw(logits))            # 取樣結果本身不帶梯度
probs  = softmax(logits)                  # 我們真正想要梯度的對象
sample = sample + probs - stop_grad(probs)  # 前向傳播值不變，反向傳播梯度視同對 probs 微分

這個技巧的巧妙之處在於：前向計算時 \(\text{sample} = \text{one\_hot}(\cdot)\)（因為 \(\text{probs}-\text{stop\_grad}(\text{probs})=0\)），但反向傳播時梯度視為直接對 \(\text{probs}=\mathrm{softmax}(\text{logits})\) 微分，等於「假裝取樣操作是恆等函數」讓梯度直接穿透，因此稱為 straight-through gradient。

4.3　世界模型損失函數與 KL Balancing

所有世界模型組件聯合最佳化以下目標（本質是條件於動作序列的隱馬可夫模型變分下界 / 序列 VAE）：

\[ \mathcal L(\phi) \doteq \mathbb E_{q_\phi(z_{1:T}\mid a_{1:T},x_{1:T})}\Big[\sum_{t=1}^{T} \underbrace{-\ln p_\phi(x_t\mid h_t,z_t)}_{\text{image log loss}} \underbrace{-\ln p_\phi(r_t\mid h_t,z_t)}_{\text{reward log loss}} \underbrace{-\ln p_\phi(\gamma_t\mid h_t,z_t)}_{\text{discount log loss}} +\beta\,\underbrace{\mathrm{KL}\big[q_\phi(z_t\mid h_t,x_t)\,\|\,p_\phi(z_t\mid h_t)\big]}_{\text{KL loss}} \Big] \]

Atari 用 \(\beta=0.1\)，連續控制用 \(\beta=1.0\)。

KL Balancing：DreamerV2 首創、DreamerV3 沿用的關鍵技巧

標準 ELBO 中的 KL 項同時扮演兩個角色：訓練先驗去逼近後驗、以及正則化後驗不要偏離先驗太多。 但動態（transition）模型一開始學得不準，若把後驗也拉向一個訓練不佳的先驗，會嚴重拖累學習。 DreamerV2 的解法是讓先驗與後驗用不同的「有效學習率」去最小化同一個 KL： 

kl_loss = alpha * compute_kl(stop_grad(posterior), prior)
        + (1 - alpha) * compute_kl(posterior, stop_grad(prior))

其中 \(\alpha=0.8\)。前項只更新先驗（讓它更快去逼近後驗），後項只更新後驗（用較慢的權重正則化它靠向先驗）。 這種「不對稱加權同一個 KL 散度」的做法，正是本教材第 6 節介紹的 DreamerV3 「\(\mathcal L_{\text{dyn}}\) 與 \(\mathcal L_{\text{rep}}\) 分別用停止梯度」的直接前身—— DreamerV3 進一步把這個機制與 free bits 結合，形式略有不同但精神完全繼承自 DreamerV2 的 KL balancing。

4.4　Actor-Critic：Reinforce 與 Straight-Through 梯度的混合

Critic 用 λ-target（遞迴定義，等價於本教材 3.3 節 \(V_\lambda\) 的離散時間版本）：

\[ V_t^\lambda \doteq \hat r_t + \hat\gamma_t \begin{cases} (1-\lambda)v_\xi(\hat z_{t+1}) + \lambda V_{t+1}^\lambda, & t

Actor loss 結合兩種梯度估計，這是 DreamerV2 相對 V1 的另一項關鍵演算法貢獻：

\[ \mathcal L(\psi) \doteq \mathbb E_{p_\phi,p_\psi}\Big[\sum_{t=1}^{H-1} \underbrace{-\rho\,\ln p_\psi(\hat a_t\mid \hat z_t)\,\mathrm{sg}(V_t^\lambda - v_\xi(\hat z_t))}_{\text{reinforce}} \underbrace{-(1-\rho)\,V_t^\lambda}_{\text{dynamics backprop}} \underbrace{-\eta\,\mathrm H[a_t\mid \hat z_t]}_{\text{entropy 正則化}} \Big] \]

為什麼 Atari 用 Reinforce、連續控制用動態反傳？

DreamerV1 完全依賴「動態反傳」（穿過 tanh-Gaussian 重參數化梯度）；但 DreamerV2 因為改用離散類別動作 （Atari 的動作空間本身離散），straight-through 梯度雖然可以反傳，卻是有偏但低方差的估計。 論文消融實驗（Table 2、Figure I.1）發現：

  • Atari（離散動作）：\(\rho=1\)（純 Reinforce）明顯優於混合或純動態反傳，因為 Reinforce 無偏，能收斂到更好的解，設定 \(\eta=10^{-3}\)。
  • 連續控制：\(\rho=0\)（純動態反傳）明顯更好，延續 DreamerV1 的做法，設定 \(\eta=10^{-4}\)。

這個「依任務類型切換梯度估計子」的權衡，到了 DreamerV3 才被 REINFORCE + return normalization 的統一方案取代，不再需要手動切換 \(\rho\)。

4.5　里程碑成果：Atari 人類水準（僅靠世界模型內部訓練）

DreamerV2 是第一個完全只在分離訓練的世界模型內部學習行為、就能在 Atari 55 款遊戲基準上達到人類水準的演算法 （Gamer Median Normalized Score 2.15，Clipped Record Mean 0.28），並在相同運算預算（單張 V100、200M 環境步、10 天）下超越 Rainbow 與 IQN 兩個強力 model-free 單 GPU 演算法。訓練期間，agent 從 468B 個「想像出來」的潛在狀態中學習， 是實際從環境接收的 5000 萬筆輸入的 10,000 倍，具體展現了世界模型帶來的樣本效率優勢。

5. DreamerV3：通用世界模型架構

5.1　RSSM：Recurrent State-Space Model

DreamerV3 的世界模型由六個組件構成，全部共用參數 \(\phi\)：

組件數學表示功能
Sequence model（序列模型）\(h_t = f_\phi(h_{t-1}, z_{t-1}, a_{t-1})\)用 GRU 遞迴更新確定性狀態 \(h_t\)
Encoder（編碼器）\(z_t \sim q_\phi(z_t \mid h_t, x_t)\)把觀測 \(x_t\) 壓成隨機潛在表徵
Dynamics predictor（動態預測器）\(\hat z_t \sim p_\phi(\hat z_t \mid h_t)\)「不看觀測」預測下一潛在狀態，是想像式訓練的關鍵
Reward predictor\(\hat r_t \sim p_\phi(\hat r_t \mid h_t, z_t)\)預測即時報酬
Continue predictor\(\hat c_t \sim p_\phi(\hat c_t \mid h_t, z_t)\)預測 episode 是否終止
Decoder（解碼器）\(\hat x_t \sim p_\phi(\hat x_t \mid h_t, z_t)\)重建觀測，強迫潛在表徵保留關鍵資訊

定義 3.1　為什麼需要「Dynamics predictor」與「Encoder」兩套潛在表徵？

Encoder 產生的 \(z_t\) 需要「看到」真實觀測 \(x_t\)，只能在訓練階段使用； 而在想像（imagination）階段，agent 必須連續預測數十步未來，卻沒有真實影像可看。 因此 Dynamics predictor \(p_\phi(\hat z_t\mid h_t)\) 學會「純粹由過去狀態猜測」潛在表徵， 其訓練目標就是去逼近 Encoder 產生的 \(z_t\)（見 3.2 節的 dynamics loss）。 這正是 model-based RL 能夠「離線做百萬步想像訓練」而不必真的操作環境的關鍵機制。

5.2　世界模型損失函數

整體世界模型損失是三項的加權和：

\[ \mathcal{L}(\phi) \doteq \mathbb{E}_{q_\phi}\left[ \sum_{t=1}^{T} \Big(\beta_{\text{pred}}\, \mathcal{L}_{\text{pred}}(\phi) + \beta_{\text{dyn}}\, \mathcal{L}_{\text{dyn}}(\phi) + \beta_{\text{rep}}\, \mathcal{L}_{\text{rep}}(\phi)\Big) \right] \]

其中 \(\beta_{\text{pred}}=1,\ \beta_{\text{dyn}}=1,\ \beta_{\text{rep}}=0.1\)（跨所有領域固定，不需調參）。

\[ \mathcal{L}_{\text{pred}}(\phi) \doteq -\log p_\phi(x_t\mid z_t,h_t) - \log p_\phi(r_t\mid z_t,h_t) - \log p_\phi(c_t\mid z_t,h_t) \]

\[ \mathcal{L}_{\text{dyn}}(\phi) \doteq \max\Big(1,\ \mathrm{KL}\big[\mathrm{sg}(q_\phi(z_t\mid h_t,x_t)) \;\|\; p_\phi(z_t\mid h_t)\big]\Big) \]

\[ \mathcal{L}_{\text{rep}}(\phi) \doteq \max\Big(1,\ \mathrm{KL}\big[q_\phi(z_t\mid h_t,x_t) \;\|\; \mathrm{sg}(p_\phi(z_t\mid h_t))\big]\Big) \]

解讀：KL Balancing 與 Free Bits

  • 停止梯度算子 \(\mathrm{sg}(\cdot)\)：dynamics loss 只更新「預測器」去逼近固定住的 encoder 輸出；representation loss 則反過來，只更新 encoder 讓其輸出更容易被預測器猜到。這種「不對稱」設計稱為 KL balancing，避免兩者互相追逐造成訓練不穩定。
  • Free bits：\(\max(1, \cdot)\) 把 KL 損失下限鎖在 1 nat（約 1.44 bits）。當 KL 已經很小時就不再懲罰，避免 posterior collapse（潛在表徵退化成與輸入無關的常數），這是深度變分自編碼器（VAE）訓練中常見的技巧。

5.3　Actor-Critic：在潛在空間中「做夢」

給定起始模型狀態，actor 與 world model 聯手在潛在空間生成想像軌跡 \(s_{1:T}, a_{1:T}, r_{1:T}, c_{1:T}\)，其中 \(T=16\)（imagination horizon）。

\[ \text{Actor: } a_t \sim \pi_\theta(a_t\mid s_t) \qquad\qquad \text{Critic: } v_\psi(R_t\mid s_t) \]

Critic 學習 λ-return（結合多步預測報酬與自身估計值，兼顧偏差與方差）：

\[ R_t^{\lambda} \doteq r_t + \gamma c_t\big[(1-\lambda)v_t + \lambda R_{t+1}^{\lambda}\big], \qquad R_T^{\lambda} \doteq v_T, \qquad \gamma = 0.997 \]

Actor 用 REINFORCE 估計器搭配 return 正規化來更新：

\[ \mathcal{L}(\theta) \doteq -\sum_{t=1}^{T} \mathrm{sg}\!\left(\frac{R_t^{\lambda}-v_t}{\max(1,S)}\right)\log \pi_\theta(a_t\mid s_t) \;+\; \eta\, \mathrm{H}\big[\pi_\theta(a_t\mid s_t)\big] \]

其中 \(S \doteq \mathrm{EMA}\big(\mathrm{Per}(R^{\lambda},95) - \mathrm{Per}(R^{\lambda},5),\,0.99\big)\) 是用 5–95 百分位差 + 指數移動平均估計的 return 尺度，\(\eta=3\times10^{-4}\) 是固定的熵正則化係數。

關鍵直覺：為什麼「除以 \(\max(1,S)\)」很重要？

不同任務的報酬尺度可能相差好幾個數量級（Atari 得分 vs. 機器人稀疏 +1 報酬）。 若直接對 advantage 做標準化（除以標準差），在報酬極稀疏時標準差趨近 0，會過度放大雜訊。 DreamerV3 改為對 return 做「只縮小過大幅值、保留小幅值不變」的正規化， 同時用固定熵係數 \(\eta\) 就能在探索不足（稀疏報酬）與過度隨機（密集報酬）之間自動取得平衡， 這正是「單一超參數組合橫跨 150+ 任務」得以成立的關鍵設計之一。

6. DreamerV3 的穩健性技巧

DreamerV3 論文的消融實驗（Fig. 6a）顯示，以下四項技巧對跨領域穩健性缺一不可：

6.1　Symlog 變換：處理跨尺度的觀測 / 報酬

\[ \mathrm{symlog}(x) \doteq \mathrm{sign}(x)\log(|x|+1), \qquad \mathrm{symexp}(x) \doteq \mathrm{sign}(x)\big(\exp(|x|)-1\big) \]

網路實際學習的是目標的 symlog 變換版本，讀出時再用 symexp 反轉：

\[ \mathcal{L}(\theta) \doteq \tfrac{1}{2}\big(f(x,\theta)-\mathrm{symlog}(y)\big)^2, \qquad \hat y \doteq \mathrm{symexp}\big(f(x,\theta)\big) \]

symlog 在原點附近近似恆等函數（不影響小數值學習），但能壓縮極大或極小的數值， 避免用平方誤差（squared loss）預測大目標時梯度爆炸，同時比 L1/Huber loss 收斂更快。

6.2　Symexp Two-Hot Loss：把回歸問題變分類問題

Reward 與 Critic 的輸出被離散成指數分佈的 bins \(B=\mathrm{symexp}([-20,\dots,+20])\)， 目標值用「兩點加權」（two-hot）編碼後，以交叉熵訓練：

\[ \mathcal{L}(\theta) \doteq -\,\mathrm{twohot}(y)^\top \log \mathrm{softmax}\big(f(x,\theta)\big) \]

好處是梯度大小完全由「分類機率誤差」決定，與目標的實際數值尺度解耦， 比起直接做回歸更穩定，尤其適合報酬分佈可能多峰、且跨數個數量級的情況（如 Minecraft 稀疏里程碑報酬 vs. Atari 密集分數）。

6.3　1% Unimix：避免類別分佈退化

Encoder、Dynamics predictor 與 Actor 的類別分佈都混合 99% 神經網路輸出 + 1% 均勻分佈，確保機率永不為 0，KL 散度數值穩定，梯度也不會消失。

6.5　里程碑成果：Minecraft 鑽石任務

在完全沒有人類資料、沒有課程學習（curriculum）的條件下，DreamerV3 是第一個能從零開始、 在 100M 環境步數內完成「原木 → 木鎬 → 石鎬 → 鐵鎬 → 鑽石」12 個里程碑的演算法， 每次訓練皆能穩定挖到鑽石（10 個種子皆成功），相較 IMPALA、Rainbow 等基準最多只能推進到鐵鎬階段。 這個結果之所以重要，是因為它證明了世界模型的「無監督重建目標」（而非任務專屬的 reward/value 梯度） 足以支撐長時間跨度、極稀疏報酬下的探索。

7. Dream to Fly：從模擬到視覺化無人機競速

7.1　問題設定：像素直接映射到 CTBR 指令

Dream to Fly 把無人機競速定義為標準 MDP \((\mathcal{X}, \mathcal{A}, P, R, \gamma)\)： 狀態 \(x_k\) 就是機載相機的原始 RGB 影像；動作 \(a_k = [c,\omega_x,\omega_y,\omega_z]\) 為「集體推力 + 機體角速度」（Collective Thrust and Body Rates, CTBR）， 這是專業競速飛手常用的操控介面，比起「位置/速度指令」更貼近底層控制，能發揮更高機動性。

\[ \pi_\theta^{*} = \arg\max_{\pi}\ \mathbb{E}\left[\sum_{k=0}^{\infty}\gamma^k r(k)\right] \]

7.2　獎勵函數設計

\[ r(k)= \begin{cases} -4.0, & \text{碰撞（collision）}\\[4pt] +10, & \text{通過閘門（gate passed）}\\[4pt] b_1\big(\lVert \mathbf g_k-\mathbf p_{k-1}\rVert - \lVert \mathbf g_k-\mathbf p_k\rVert\big) - b_2\lVert \boldsymbol\omega_k\rVert, & \text{其他} \end{cases} \]

其中 \(b_1=1.0,\ b_2=0.01\)。第一項是「進度獎勵」（progress term）——只要靠近目標閘門就給正報酬， 不限制飛行路徑必須貼合預設航點，讓 agent 有空間自行發現更有效率的軌跡； 第二項則懲罰過大角速度，避免震盪或不穩定機動。

PPO vs. DreamerV3：直接像素輸入的訓練曲線對比

論文在 Circle / Kidney / Figure-8 三種賽道上，以相同的原始像素輸入比較 PPO 與 DreamerV3： PPO 在 1000 萬步互動內幾乎沒有學到任何有效飛行行為（reward 曲線幾乎持平於谷底）， 而 DreamerV3 能穩定收斂並飛出完整賽道。這直接驗證了 Model-Based RL 在高維像素輸入、 即時控制任務上的樣本效率優勢 —— 世界模型讓 agent 可以在「想像」中訓練上千萬步， 而不必真的渲染那麼多影格。

7.3　四旋翼名義動力學（Nominal Dynamics）

狀態 \(\vec x = [\vec p_I, \vec q_{IB}, \vec v_I]^\top\)（位置、機體到慣性系的單位四元數、線速度）：

\[ \dot{\vec p} = \vec v, \qquad \dot{\vec v} = \vec g + \frac{\mathbf R(\vec q)\,\vec f_T}{m}, \qquad \dot{\vec q} = \frac{\vec q}{2}\odot[0\ \ \vec\omega]^\top \]

這是典型的剛體四元數運動學表示，與您在 CURIO SE(3) 幾何控制器研究中使用的四元數 Mahony AHRS 架構是同一套數學語言 —— 世界模型的 Dynamics Predictor 事實上就是在「用神經網路學習一個近似版的 \(\dot{\vec x}=\vec f(\vec x,\vec u)\)」。

7.4　關鍵發現：突現的「感知導向」行為（Perception-Aware Emergent Behavior）

訓練完成後，agent 會自發地把相機視角朝向下一個閘門，即使獎勵函數中完全沒有鼓勵「看向閘門」的項。 論文透過一個巧妙的消融實驗驗證了這個現象：在賽道外圍加入兩個「假閘門」（只出現在渲染畫面、不需真正穿越）， 結果訓練出的策略會把注意力平均分配到真假閘門之間 —— 證明 agent 學到的是「主動朝向資訊豐富區域」的通用策略， 而不是死記閘門位置。這是因為：

  1. End-to-end 從像素到指令的訓練，讓「感知」與「動作」的迴路被打通（closed action-perception loop）；
  2. 影像被降採樣到 \(64\times64\) 後，閘門邊緣仍然清晰，但背景細節模糊，world model 的重建損失自然驅使策略聚焦於資訊量高的區域。

8. SkyDreamer：Informed Dreamer 與端到端實機部署

8.1　Informed POMDP：訓練時「開特權外掛」，部署時不依賴它

SkyDreamer 建立在 Informed Dreamer（Lambrechts et al.）之上，將問題形式化為 Informed POMDP：

\[ \widetilde{\mathcal P} = (\mathcal S,\mathcal U,\mathcal I,\mathcal O,T,R,\widetilde{I}_e,\widetilde{O}_e,P,\gamma) \]

其中資訊變數 \(i_t = [o_t,\ o_t^{+}]^\top\) 是「觀測」與「僅訓練時可見的特權觀測」的串接。 World model 在訓練階段被要求解碼出特權資訊 \(o_t^{+}\)（真實位置、速度、姿態、相機外參、動力學參數等），

\[ \text{Decoder: } i_t \sim p^i_\theta(\cdot \mid h_t, z_t) \]

但部署時策略只能存取觀測歷史 \(h_t=(o_0,u_0,\dots,o_t)\)，不再有特權資訊。 最優策略定義為：

\[ \pi_\theta^{*} = \arg\max_{\pi_\theta}\ \mathbb{E}_{\substack{s_0\sim P(\cdot)\\ u_t\sim\pi_\theta(\cdot\mid h_t)\\ s_{t+1}\sim T(\cdot\mid s_t,a_t)\\ o_t\sim \widetilde{O}_e(\cdot\mid s_t)}} \left[\sum_{t=0}^{\infty}\gamma^t R(s_t,a_t)\right] \]

與標準 DreamerV3 的關鍵差異

標準 DreamerV3（見第 5 節）的 decoder 只重建觀測本身 \(\hat x_t \sim p_\phi(\hat x_t\mid h_t,z_t)\)。 而 SkyDreamer 改為重建真實狀態（位置、速度、姿態、相機外參、動力學參數等）， 這帶來兩個好處：

  • 可解釋性（interpretability）：可以直接檢視 world model 「認為」現在的位置、速度是多少， 而不像重建影像那樣只能得到模糊的像素預測，方便除錯（不需要每次都重新試飛）。
  • 加速學習：world model 被強迫抽取「任務相關」的特徵（位置、姿態等可從影像序列復原的量）， 而非浪費容量去重建視覺細節，這對高維像素輸入的收斂速度與最終表現有顯著幫助。

8.2　狀態空間與觀測空間

完整狀態向量（部分僅訓練時可見）：

\[ \mathbf s = [\mathbf p_w, \mathbf p_g, \mathbf v_w, \mathbf v_g, \boldsymbol\lambda, \boldsymbol\Omega, \boldsymbol\omega, \mathbf c_e, \mathbf d, \boldsymbol\varepsilon, \mathbf f]^\top \]

符號物理意義是否為特權資訊
\(\mathbf p_w,\mathbf v_w,\boldsymbol\lambda\)世界座標位置 / 速度 / 姿態是
\(\boldsymbol\Omega,\boldsymbol\omega\)機體角速度 / 螺旋槳轉速（真值）是（觀測用的是量測值 \(\hat{\boldsymbol\Omega},\hat{\boldsymbol\omega}\)）
\(\mathbf c_e\)相機外參（機體到相機的尤拉角）是
\(\mathbf d\)動力學隨機化參數（推力係數、馬達最大轉速等）是
\(\mathbf f\)Flight plan 向量（下三個閘門的相對位置/偏航）否（觀測輸入）
\(\mathbf X\)二值化閘門分割遮罩（binary segmentation mask）否（觀測輸入）

8.3　動作空間：直接輸出馬達 PWM（無內迴路控制器）

與 Dream to Fly 使用 CTBR 不同，SkyDreamer 的動作 \(\mathbf u_t=[u_1,u_2,u_3,u_4]^\top,\ u_i\in[0,1]\) 是四顆馬達各自的正規化 PWM 指令，這個設計呼應 ESA 提出的 Guidance & Control Networks (G&CNET) 概念 —— 神經網路直接取代整個「內迴路控制器（PID / INDI）」，理論上能取得比串接式控制架構更高的控制權限與機動性上限。

8.4　獎勵函數與碰撞終止條件

\[ r_t = 5\cdot r_{\text{prog}} - r_{\text{rate}} + 30\cdot r_{\text{gate}} \]

\[ r_{\text{rate}} = \frac{1}{2 f_c \times 10^5}\Big(\exp\big(\min(\lVert\boldsymbol\Omega_t\rVert_1,17)\big)-1\Big) \]

\[ r_{\text{prog}} = \lVert \mathbf p_{t-1,g}\rVert_2 - \lVert \mathbf p_{t,g}\rVert_2 \qquad r_{\text{gate}} = \begin{cases} 1-\dfrac{\max(|y_{t,g}|,|z_{t,g}|)}{d_g}, & \text{通過閘門}\\[8pt] 0, & \text{其他} \end{cases} \]

其中 \(f_c=90\ \mathrm{Hz}\) 為控制頻率。\(r_{\text{rate}}\) 用指數函數懲罰過大角速度， 目的是避免陀螺儀飽和與過度動態模糊（motion blur）；\(r_{\text{gate}}\) 在閘門中心給最大值、邊緣線性遞減至 0， 鼓勵精準穿越而非擦邊而過。與 Dream to Fly 不同，SkyDreamer刻意不加碰撞懲罰項， 因為實驗發現碰撞懲罰反而阻礙學習，讓「episode 提前終止導致的折現報酬損失」自然發揮懲罰效果就足夠。

8.5　Flight Plan 邏輯：解決視覺歧義（Visual Ambiguity）

什麼是視覺歧義？

賽道設計中常出現「不同路段、視覺上卻幾乎一樣」的情況（例如 ladder / inverted-loop 賽道中， 無人機會從不同角度、不同時間點兩次靠近同一個閘門，畫面幾乎相同，但正確的下一步機動卻不同）。 純粹依賴「當前影像」的端到端策略在此類賽道上會失效，因為 POMDP 的觀測不足以決定正確動作。

SkyDreamer 引入 flight plan 向量 \(\mathbf f_i\)，內含「未來三個閘門」的相對位置與偏航角差：

\[ \mathbf f_i = \Big[\ \mathbf p_i^g - \mathbf p_{i-1}^g,\ \psi_i^g-\psi_{i-1}^g,\ \dots,\ \mathbf p_i^g,\ \psi_i^g,\ \dots,\ \psi_{i+2}^g\ \Big]^\top \]

並用 world model 解碼出的閘門相對位置估計 \(\hat{\mathbf x}_g\) 來判斷是否已通過當前閘門 （觸發條件 \(\hat{\mathbf x}_g > -0.15\ \mathrm{m}\)），進而更新 flight plan 索引 \(i\)。 這個機制本質上是把「離散的任務進度」（賽道上第幾段）明確地餵給策略， 彌補了純視覺觀測在 POMDP 意義下的不完備性，也為未來「飛任意未知賽道」的泛化能力奠定基礎。

8.6　視覺 Sim-to-Real：CycleGAN / StochGAN

渲染出的理想化分割遮罩與真實相機透過分割網路（GateNet, U-Net 架構）產出的遮罩之間存在明顯落差 （真實遮罩較細、有雜訊、邊緣不規則）。SkyDreamer 用約 4000 張未配對的真實/渲染影像訓練 StochGAN（CycleGAN 的隨機化延伸版本，於輸入加入噪聲通道）， 把渲染遮罩轉換得更接近真實分佈，並額外做隨機腐蝕（erosion）模擬真實遮罩偏細的現象， 以及用仿射變換模擬 rolling shutter 相機在角速度下產生的水平剪切與垂直縮放效應：

\[ A = \begin{bmatrix} 1 & -s\,r_c & \frac{W}{2}s\,r_c \\ s\,q_c & 1+s\,q_c & -\frac{H}{2}s\,q_c \end{bmatrix}, \qquad \mathbf X' = \mathrm{warp\_affine}(\mathbf X, A) \]

其中 \(r_c, q_c\) 分別為相機座標系下的偏航角速度與俯仰角速度，\(s\in[0,0.02]\) 為隨機化的 rolling shutter 係數。

8.7　平滑正則化：避免 Bang-Bang 控制燒毀馬達

純粹用標準 DreamerV3 訓練直接輸出 PWM 的策略，容易收斂到「馬達不是全開就是全關」的 bang-bang 行為 —— 在模擬中最優，實機上卻會導致馬達過熱甚至燒毀。SkyDreamer 只對策略分佈的均值加平滑正則化 （避免與熵正則化互相打架）：

\[ \mathcal{L}_{\text{smooth}} = \lambda_{\text{smooth}}\, \mathbb{E}_t\big[\lVert \mu_t - \mu_{t-1}\rVert_2^2\big], \qquad \lambda_{\text{smooth}}=0.002 \]

9.3　六篇論文的 V／M／C 訓練方法綜合比較

三條清楚的演進主軸

  • V 與 M 從「兩階段獨立訓練」走向「單一 RSSM 聯合訓練」：World Models 中 V 先訓練、凍結，M 才用 V 輸出的 \(z\) 訓練， 兩者訓練目標互不相干（V 不知道任務、M 不影響 V 的表徵）；DreamerV1 開始把這兩者合併成同一個 RSSM， 用單一 ELBO 聯合最佳化，讓 V 學到的表徵天生就對「M 是否能準確預測未來」與「reward 預測」負責， 這正是 9.3(1) 表格「輸出資料」欄位從單純「重建影像」演變為「潛在分佈 + 獎勵/終止預測」的關鍵原因。
  • C 從「無梯度演化」走向「有梯度的想像式策略梯度」：World Models 用 CMA-ES 只需要標量報酬即可訓練， 完全不需要世界模型可微分；DreamerV1 反過來要求世界模型必須可微分，才能把梯度解析地反傳穿越想像軌跡； DreamerV2/V3 則改用 REINFORCE，放棄解析梯度以換取離散動作與更廣泛任務的支援。 三者代表了「樣本效率 vs. 適用範圍 vs. 實作複雜度」的不同取捨點。
  • M 的輸出內容隨應用場景不斷擴充：從最初只預測下一個潛在向量 \(z_{t+1}\)（World Models 的 CarRacing）， 到加入終止訊號 \(d_{t+1}\)（World Models 的 VizDoom，使其可完整替代 Gym 環境）， 到加入獎勵與 continue flag（Dreamer 系列，使其可支援任意 RL 任務）， 再到加入特權狀態解碼（SkyDreamer，使其在犧牲一些訓練複雜度的前提下換取部署時的可解釋性）—— M 預測的目標，本質上反映了「這個世界模型被要求承擔多少下游任務的責任」。

批判性思考：五篇論文各自的侷限

  • DreamerV1：僅支援連續動作，離散動作與提早終止（early termination）任務尚未妥善處理；解析梯度反傳依賴動態模型本身足夠準確，模型誤差會直接累積進策略梯度中，缺乏 V2 之後對此問題的系統性處理。
  • DreamerV2：需要「依任務類型手動切換」\(\rho\)（Atari 用純 Reinforce、連續控制用純動態反傳），並未真正做到跨任務單一組態；世界模型與策略分離訓練雖證明可行，但仍需完整 55 款遊戲 × 10 天調參驗證才能確立超參數，泛用性尚待 V3 補強。
  • DreamerV3：雖然聲稱「固定超參數」，但 Minecraft 任務仍需要放大模型規模（200M 參數）與加速破壞方塊速度等任務特化設計，並非完全零調整；另外單次訓練仍需 9 天 × 1 GPU，對即時性應用（如飛控）而言仍偏慢。
  • Dream to Fly：最高速度僅 8 m/s，且從未驗證真實相機影像的 sim-to-real gap（HIL 只驗證動力學迴路），距離「真正端到端實機部署」尚有一步之遙；这也是 SkyDreamer 存在的動機。
  • SkyDreamer：解碼的狀態估計存在高頻跳動（可能來自離散潛在表徵 \(z_t\) 的量化特性）；動力學參數估計品質因訓練種子而異，部分參數（如偏航效率 \(k_{r1}\)）估計失敗；且訓練仍需約 50 小時 GPU 運算。

10. 數學附錄：關鍵推導與符號整理

10.1　為什麼 λ-return 是偏差與方差的折衷？

純粹的 Monte-Carlo return（\(\lambda=1\)）方差大但無偏；純粹的一步 TD target（\(\lambda=0\)）方差小但有偏（依賴 critic 本身估計的準確度）。 λ-return 透過遞迴混合：

\[ R_t^{\lambda} = r_t + \gamma c_t\Big[(1-\lambda)\,v(s_{t+1}) + \lambda\, R_{t+1}^{\lambda}\Big] \]

可以展開成「所有 n-step return 的指數加權平均」，在 \(0<\lambda<1\) 時取得偏差-方差的平滑折衷。 DreamerV3 與 SkyDreamer 皆使用 \(\lambda=0.95\)（Extended Data Table 5）。

10.2　REINFORCE 估計器的推導骨架

策略梯度的目標是最大化期望報酬 \(J(\theta)=\mathbb{E}_{\pi_\theta}[R]\)。利用 log-derivative trick：

\[ \nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\big[R\cdot \nabla_\theta \log \pi_\theta(a\mid s)\big] \]

實作上用 advantage \((R_t^\lambda - v_t)\) 取代原始報酬 \(R\) 以降低方差（baseline trick，不改變期望值但顯著降低估計方差）， 再加上熵正則化項 \(\eta\,\mathrm H[\pi_\theta]\) 鼓勵探索，即得到第 3.3 節的 actor loss。

10.3　KL 散度與變分下界（ELBO）的關係

DreamerV3 的世界模型訓練本質上是在最大化一個變分下界（類似 VAE 的 ELBO）， 其中 reconstruction term 對應 \(\mathcal L_{\text{pred}}\)，KL 正則項對應 \(\mathcal L_{\text{dyn}}+\mathcal L_{\text{rep}}\)。標準 VAE 的 KL 項為：

\[ \mathrm{KL}\big[q_\phi(z\mid x)\,\|\,p(z)\big] \]

而 DreamerV3 把「先驗」\(p(z)\) 換成了「由 \(h_t\) 預測出的動態先驗」\(p_\phi(z_t\mid h_t)\)， 這使得先驗本身也是可學習、且與時間序列相關的 —— 這正是 RSSM 與標準 VAE 最本質的差異： 標準 VAE 的先驗通常是固定的標準常態分佈，而 RSSM 的先驗會隨遞迴狀態演化，具備「預測未來」的能力。

11. 對 UAV 控制研究的啟示與延伸思考

11.1　與傳統飛控架構的對照

您在 CURIO / Betaflight / Crazyflie 相關研究中所熟悉的串接式飛控架構（外環姿態 → 內環角速度 → 混控矩陣 → PWM）， 本質上是「人類手工設計的狀態估計 + 控制律」。而本教材五篇論文展示的是另一條路線：

傳統模組化飛控

  • 顯式狀態估計（EKF / Mahony AHRS）
  • 顯式控制律（PID / INDI / SE(3) 幾何控制）
  • 可解釋性高、可形式化穩定性證明（如 Routh-Hurwitz）
  • 需要精確建模與大量手動調參

World Model + RL 端到端

  • 隱式狀態估計（world model 潛在表徵，SkyDreamer 進一步解碼為可讀狀態）
  • 學習得到的控制策略（actor 網路直接輸出 PWM）
  • 可解釋性較低，但 SkyDreamer 透過「解碼特權狀態」大幅緩解此問題
  • 需要大量模擬訓練與 sim-to-real 技巧，但一旦訓練完成，可自動適應動力學參數變化（如電池衰減）

11.2　可能的研究連結點

  • 線上參數辨識：SkyDreamer 的隱式線上估計 \(\hat\omega_{\max}\)、\(\hat k_w\) 現象， 與您在 CURIO 中做的 relay-feedback autotuning（Åström–Hägglund 方法）、頻域辨識可以互相對照 —— 一個是「顯式頻域方法」，一個是「隱式神經網路推論」，未來或可探討兩者結合（例如用 world model 的線上估計初始化顯式辨識， 或反過來用顯式模型作為 world model 的先驗）。
  • SE(3) 幾何控制 vs. 學習型控制：CURIO4 的 SO(3) vee-map 誤差公式化提供了「精確、可證明穩定」的姿態控制， 而 DreamerV3/SkyDreamer 的 actor-critic 則是「資料驅動、可自動適應未建模動態」的替代方案。 兩者互補的可能方向：用 SE(3) 控制器作為 imitation learning 的初始策略，加速 world model 訓練收斂。
  • 四層 I2C 匯流排保護、EKF 導航系統等硬體/估計工作，某種程度上正是為了取得 SkyDreamer 中 \(o_t^+\) （特權觀測）在實機上「無法取得」時所需的替代方案 —— 換言之，World Model 方法某種程度上是用大量模擬訓練 換取對精確狀態估計硬體（如高精度 IMU 融合）的依賴降低。
  • 教學用途：若要在「零到飛」課程中示範 World Model 概念，可以考慮用簡化版 RSSM（例如僅用低維向量觀測， 而非影像）在您既有的 pivot stand PID 平衡台或 MATLAB 雙迴路模擬 app 基礎上，加開一個「MBRL 對照組」， 讓學生直觀比較 PID/SE(3) 控制與學習型控制在同一個平台上的差異。

11.3　實務落地的現實限制

在把 World Model + RL 導入實際 UAV 研究前，應注意：

  • 訓練成本：DreamerV3 單一 A100 GPU 訓練 Minecraft 任務需 9 天；SkyDreamer 完整訓練約 50 小時。 對於資源有限的實驗室（單張消費級 GPU），需要縮小模型規模或降低 replay ratio，會犧牲部分效能。
  • 模擬器精度需求：SkyDreamer 之所以能做到高機動性 sim-to-real 轉移，仰賴精細校準的四旋翼動力學模型 （含馬達回應時間常數 \(\tau\)、螺旋槳氣動力矩耦合項等），這類建模工作量不亞於傳統控制器設計。
  • 安全性驗證：學習型策略缺乏形式化穩定性保證，不適合直接用於對安全性要求極高的應用（如載人飛行器）， 仍需搭配傳統控制的安全網（例如幾何圍籬、失效保護邏輯）。

12. 課後習題

  1. 推導題：試證明 λ-return 遞迴式 \(R_t^{\lambda} = r_t + \gamma c_t[(1-\lambda)v_{t+1}+\lambda R_{t+1}^{\lambda}]\) 展開後等價於所有 n-step return 的指數加權平均 \(R_t^{\lambda} = (1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}R_t^{(n)}\)（假設 episode 不終止的情況下）。
  2. 概念題（DreamerV1）：DreamerV1 用「解析梯度反傳」訓練 actor，而非 A3C/PPO 常用的 REINFORCE。 請說明這兩種梯度估計方式在偏差（bias）與方差（variance）上的差異，並解釋為什麼解析梯度反傳需要一個 「可微分」的世界模型才能成立。
  3. 概念題（DreamerV2）：DreamerV2 的 straight-through 梯度估計器讓前向傳播使用離散 one-hot 取樣、 反向傳播卻視同對 softmax 機率微分。請解釋這種做法為什麼是「有偏但低方差」，並比較它與 DreamerV1 重參數化梯度（reparameterization，無偏但要求分佈可重參數化）的適用場景差異。
  4. 概念題：解釋為什麼 DreamerV3 的 dynamics loss 與 representation loss 需要對「不同」的分佈套用停止梯度（KL balancing）？ 這個機制與 DreamerV2 首創的 KL balancing（\(\alpha=0.8\) 不對稱加權）有何異同？ 若把兩者的權重設成相同會發生什麼問題？
  5. 比較題：Dream to Fly 使用 CTBR 動作空間，SkyDreamer 使用直接馬達 PWM。 請從「策略搜尋空間大小」與「機動性上限」兩個角度，分析這個設計差異對訓練難度與最終飛行表現可能帶來的影響。
  6. 設計題：若要把 SkyDreamer 的 Flight Plan 邏輯應用到您的 CURIO 平台（假設要飛一個 8 字形賽道）， 請設計一個合理的 flight plan 向量結構，並說明如何利用 world model 解碼的相對位置來觸發閘門索引更新。
  7. 批判題：DreamerV3 論文宣稱使用「固定超參數」橫跨所有任務，但 SkyDreamer 訓練中卻分三階段調整了 batch length、entropy coefficient 與 learning rate。這是否違背了 DreamerV3 論文的核心主張？ 請論證你的立場並舉出論文中的具體證據。
  8. 實作題（進階）：嘗試用簡化的 RSSM（例如僅 32 維離散潛在表徵、單層 GRU）在您的雙迴路 PID 模擬平台上， 以低維向量觀測（而非影像）訓練一個 world model，比較其想像出的軌跡與真實模擬軌跡的誤差隨想像步數增加的發散情形。
