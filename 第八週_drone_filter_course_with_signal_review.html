濾波器種類與四軸無人機飛控應用

碩士班授課教材｜頻域分析 × 時域分析 × 現代飛控系統 × Betaflight 實務

為何飛控需要濾波器？

四軸無人機的飛控系統（Flight Controller）必須從多個感測器（IMU、陀螺儀、加速度計、氣壓計、GPS）取得即時數據。然而，這些訊號混雜了：

  • 高頻雜訊：馬達震動、螺旋槳氣動噪音（數百 Hz 至數 kHz）
  • 低頻漂移：感測器零點偏移、溫度漂移
  • 窄帶干擾：特定頻率的機械共振（如機臂共振頻率）

濾波器的核心任務是分離有效訊號與干擾，確保 PID 控制器接收到乾淨的姿態與角速度反饋。

為什麼用卷積運算時域響應？

這是飛控濾波器設計中最核心的數學問題。為什麼線性時不變（LTI）系統的時域響應可以用卷積（Convolution）求出？

最根本的答案是：任何輸入訊號，都可以看成無數個「延遲後、加權後的 impulse（衝擊）」相加；而 LTI 系統對每一個 impulse 的反應，就是 impulse response h(t)。利用線性與時不變性，把所有反應加起來，就自然得到卷積。

1. LTI 系統的基本性質

假設一個系統：x(t) → H → y(t)

  • x(t)：輸入訊號
  • y(t)：輸出訊號
  • h(t)：系統的 impulse response

例如四軸無人機的 Roll rate dynamics：

τₓ(t) → G(s) → ωₓ(t) // 若已知 impulse response h(t)，則任意輸入的輸出皆可由卷積求得

線性（Linearity）

若 x₁(t)→y₁(t) 且 x₂(t)→y₂(t) 則 a·x₁(t)+b·x₂(t) → a·y₁(t)+b·y₂(t) // 輸入放大 a 倍，輸出也放大 a 倍；多個輸入的總響應等於個別響應之和

時不變性（Time Invariance）

若 x(t)→y(t) 則 x(t-τ)→y(t-τ) // 輸入延遲 τ 秒，輸出形狀不變，僅整體延遲 τ 秒
飛控系統中的濾波器（PT1、BiQuad、Notch）皆為 LTI 系統，因此卷積是分析它們時域行為的通用工具。

2. 任意訊號的 Impulse 分解

這是最重要的一步。連續時間訊號 x(t) 可以表示為：

x(t) = ∫₋∞^∞ x(τ)·δ(t-τ) dτ // δ(t-τ) 為發生在時間 τ 的單位衝擊

意思是：在每一個時間 τ，都有一個大小為 x(τ) 的 impulse。把所有時間的 impulses 加起來（積分），就重新構成原本的訊號。

直觀圖解

假設輸入是一連串小脈衝：

Input x(t) ↑ ↑ ↑ ↑ ↑ │ │ │ │ │ ──┴────┴──────┴───────┴────┴──→ t τ₁ τ₂ τ₃ τ₄ τ₅ 每一個 x(τᵢ)·δ(t-τᵢ) 都是一個「加權、延遲」的衝擊

3. 從 Impulse Response 到卷積

步驟一：單一 Impulse 的響應

輸入: δ(t) → 輸出: h(t) （impulse response 的定義）

步驟二：延遲 Impulse 的響應（時不變性）

輸入: δ(t-τ) → 輸出: h(t-τ) // 響應形狀不變，僅延遲 τ 秒

步驟三：加權 Impulse 的響應（線性）

輸入: x(τ)·δ(t-τ) → 輸出: x(τ)·h(t-τ) // 輸入放大 x(τ) 倍，輸出也放大 x(τ) 倍

步驟四：疊加所有響應（線性疊加）

原始輸入: x(t) = ∫ x(τ)·δ(t-τ) dτ 每一個 impulse 產生: x(τ)·h(t-τ) 利用線性系統的 superposition: y(t) = ∫₋∞^∞ x(τ)·h(t-τ) dτ = x(t) * h(t) // 這就是卷積積分！
為什麼是 h(t-τ) 而不是 h(τ)？

τ 代表「這個輸入 impulse 發生的時間」。假設現在觀察輸出時間 t，那麼在過去 τ 發生的 impulse，到現在已經響應了 t-τ 秒。因此我們要看 impulse response 的 h(t-τ)。

4. 一階系統範例

假設系統傳遞函數：

G(s) = 1/(s+a) 其 impulse response 為: h(t) = e^(-at)·u(t) 假設輸入為 step input: x(t)=u(t) 則輸出: y(t) = x(t)*h(t) = ∫₋∞^∞ u(τ)·e^(-a(t-τ))·u(t-τ) dτ 由於兩個 unit step 限制積分範圍: 0 ≤ τ ≤ t y(t) = ∫₀^t e^(-a(t-τ)) dτ = e^(-at) · ∫₀^t e^(aτ) dτ y(t) = (1/a)·[1 - e^(-at)] // 這正是 G(s)=1/(s+a) 對 step input 的時域響應

5. 時域卷積 ↔ 頻域乘積

這也是卷積在控制系統中如此重要的原因：

時間域: y(t) = x(t) * h(t) Laplace 變換: Y(s) = X(s)·H(s) 因此: L{x(t)*h(t)} = X(s)·H(s) 時域 Convolution ⟷ s-domain Multiplication // 控制系統通常先寫 Y(s)=G(s)·U(s)，因為乘法比直接做卷積容易很多 // 然後 y(t)=L⁻¹[G(s)·U(s)]，這個 inverse Laplace 本質上就是在求 y(t)=u(t)*h(t)
飛控教材中的頻域分析（傳遞函數 H(s)、Bode 圖）與時域分析（差分方程、脈衝響應）透過 Laplace 變換緊密連結。嵌入式飛控最終執行的是時域差分方程，但參數設計通常在頻域完成。

假設你在四軸上瞬間施加一個 Roll torque：τ(t)=δ(t)

它不會只在那一瞬間有輸出。無人機會經歷：

所以現在的輸出 y(t) 其實是：

y(t) = ∫「過去輸入 x(τ)」×「到現在的響應 h(t-τ)」dτ // 系統記住過去每一個瞬間輸入所造成的影響，然後在現在把所有尚未消失的影響累積起來
卷積並不是什麼「額外發明出來的數學技巧」。它實際上就是：系統記住過去每一個瞬間輸入所造成的影響，然後在現在把所有尚未消失的影響累積起來。這正是飛控濾波器（PT1、BiQuad）在時域中運作的本質。

一階低通濾波器（First-Order LPF / PT1）

頻域分析

連續時間傳遞函數: H(s) = Y(s)/X(s) = ωc/(s+ωc) = 1/(τs+1) 其中 ωc = 2π·fc 為截止角頻率，τ = 1/ωc 為時間常數。 頻率響應（令 s=jω）: H(jω) = 1/(1+jωτ) = 1/(1+jω/ωc) 幅度響應: |H(jω)| = 1/√(1+(ω/ωc)²) • ω=0 (DC): |H|=1 (0 dB) • ω=ωc: |H|=1/√2 ≈ 0.707 (-3 dB) • ω→∞: |H|→0 (-20 dB/decade) 相位響應: ∠H(jω) = -arctan(ω/ωc) • ω=0: 相位 = 0° • ω=ωc: 相位 = -45° • ω→∞: 相位 → -90° 群延遲（時域相位延遲度量）: τg(ω) = -d∠H/dω = τ/(1+(ωτ)²) • 低頻時 τg ≈ τ = 1/ωc（最大延遲） • 高頻時 τg → 0

時域分析 — 微分方程

由 H(s)=1/(τs+1)，交叉相乘取反拉氏變換: τ·dy(t)/dt + y(t) = x(t) dy(t)/dt = (1/τ)·[x(t)-y(t)] // 輸出 y(t) 以速率 1/τ 向輸入 x(t)「追趕」

時域分析 — 脈衝響應 h(t)

對 x(t)=δ(t)，初始條件 y(0⁺)=1/τ: h(t) = (1/τ)·e^(-t/τ)·u(t) // 系統對瞬間衝擊的記憶呈指數衰減，τ 越大衰減越慢

時域分析 — 階躍響應 g(t)

對 x(t)=u(t): g(t) = [1-e^(-t/τ)]·u(t) • t=τ: g(τ)=1-e⁻¹≈0.632 (63.2%終值) • t=3τ: g(3τ)≈0.950 (95%終值) • t=5τ: g(5τ)≈0.993 (99.3%終值)

時域分析 — 卷積積分

y(t) = x(t)*h(t) = (1/τ)·∫₀^t x(τ')·e^(-(t-τ')/τ) dτ' // 指數加權移動平均：越近輸入權重越大

離散時域 — 差分方程（後向歐拉法）

dy/dt≈[y[n]-y[n-1]]/Ts 代入: y[n] = α·x[n] + (1-α)·y[n-1] α = Ts/(τ+Ts) = ωc·Ts/(1+ωc·Ts) // 嵌入式最常用遞迴式！1次乘法+1次加法+1次移位 // 即為 Betaflight 中 pt1FilterApply() 的核心實現
時域直觀：y[n] 是「當前輸入的小部分 α」加上「過去輸出的絕大部分 (1-α)」。α 越小系統越「懶惰」，越依賴歷史；α 越大越「敏感」，反應快但雜訊大。

二階低通濾波器（BiQuad / PT2）

頻域分析

標準二階低通傳遞函數: H(s) = ωc²/(s²+2ζωc·s+ωc²) ζ（zeta）為阻尼比。ζ=1/√2≈0.707 時為 Butterworth 響應，具有最大平坦通帶。 頻率響應幅度: |H(jω)| = 1/√[(1-(ω/ωc)²)²+(2ζω/ωc)²] • 低頻 (ω<<ωc): |H|≈1 (0 dB) • 截止點 (ω=ωc): |H|=1/(2ζ) - Butterworth (ζ=0.707): |H|=1/√2 (-3 dB) • 高頻 (ω>>ωc): |H|≈(ωc/ω)² → -40 dB/decade 相位響應: ∠H(jω) = -arctan[2ζω/ωc / (1-(ω/ωc)²)] • ω=0: 0° • ω=ωc: -90° • ω→∞: -180° 群延遲比一階更大，尤其在截止頻率附近。

時域分析 — 微分方程

d²y/dt² + 2ζωc·dy/dt + ωc²·y = ωc²·x // 與彈簧-阻尼-質量系統（Spring-Mass-Damper）同構

時域分析 — 脈衝響應（三種阻尼情況）

欠阻尼 (0<ζ<1): h(t)=(ωc/√(1-ζ²))·e^(-ζωc·t)·sin(ωd·t)·u(t) ωd=ωc·√(1-ζ²) 臨界阻尼 (ζ=1): h(t)=ωc²·t·e^(-ωc·t)·u(t) 過阻尼 (ζ>1): h(t)=[ωc/(2√(ζ²-1))]·[e^(-(ζ-√(ζ²-1))ωc·t)-e^(-(ζ+√(ζ²-1))ωc·t)]·u(t)

時域分析 — 階躍響應（欠阻尼）

g(t)=[1-e^(-ζωc·t)·(cos(ωd·t)+(ζ/√(1-ζ²))·sin(ωd·t))]·u(t) • 超調量: OS=e^(-ζπ/√(1-ζ²))×100% - ζ=0.707 (Butterworth): OS≈4.3% - ζ=1.0 (臨界阻尼): OS=0% • 安定時間(±2%): ts≈4/(ζωc)

離散時域 — BiQuad 差分方程

經雙線性變換（Tustin 法）: y[n]=b0·x[n]+b1·x[n-1]+b2·x[n-2]-a1·y[n-1]-a2·y[n-2] // 需儲存 x[n-1],x[n-2],y[n-1],y[n-2] // 每週期: 3次乘法+4次加法+2次移位 // Betaflight 的 biquadFilter_t 結構儲存這些係數
飛控選擇：Butterworth（ζ=1/√2）通帶最平坦，超調僅4.3%，是飛控 BiQuad 首選阻尼比。

PT1 / PT2 / PT3 級聯濾波器

頻域分析

PTn: H(s) = [ωc/(s+ωc)]ⁿ PT1: -20 dB/dec 衰減 PT2: -40 dB/dec 衰減 PT3: -60 dB/dec 衰減 級聯的優點是計算簡單、數值穩定，且每級可獨立調整截止頻率。

時域分析

n個相同PT1級聯的脈衝響應: h_n(t)=[t^(n-1)/((n-1)!·τ^n)]·e^(-t/τ)·u(t) // Gamma分布的PDF形式 // n=1: 指數分布 | n=2: Erlang分布 | n=3: 拋物線上升後指數衰減 階躍響應初始斜率: • PT1: dg/dt|₀=1/τ • PT2: dg/dt|₀=0（S型曲線，更平滑） • PT3: dg/dt|₀=0, d²g/dt²|₀=0（更延遲但更平滑）

高通濾波器（HPF）

頻域分析

一階高通傳遞函數: H(s) = s/(s+ωc) = τs/(τs+1) 頻率響應（令 s=jω）: H(jω) = jωτ/(1+jωτ) 幅度響應: |H(jω)| = (ω/ωc)/√(1+(ω/ωc)²) • ω=0 (DC): |H|=0 (-∞ dB，完全衰減) • ω=ωc: |H|=1/√2 ≈ 0.707 (-3 dB) • ω→∞: |H|→1 (0 dB，無衰減通過) 相位響應: ∠H(jω) = 90° - arctan(ω/ωc) • ω=0: 相位 = +90° • ω=ωc: 相位 = +45° • ω→∞: 相位 → 0° 與 LPF 的關係: H_LPF(s) + H_HPF(s) = ωc/(s+ωc) + s/(s+ωc) = 1 // 這是「互補」的數學根源：LPF+HPF=1

時域分析 — 微分方程

τ·s·Y(s)+Y(s)=τ·s·X(s) τ·dy/dt + y = τ·dx/dt dy/dt = dx/dt - (1/τ)·y // 右邊出現輸入導數項 dx/dt，對「變化率」敏感，對恆定輸入無響應

時域分析 — 脈衝響應

H(s)=1-ωc/(s+ωc) h(t)=δ(t)-(1/τ)·e^(-t/τ)·u(t) =δ(t)-h_LPF(t) // 正衝擊直接通過 + 負指數尾確保總面積為零（直流增益=0）

時域分析 — 階躍響應

對 x(t)=u(t)，dx/dt=δ(t): g(t)=e^(-t/τ)·u(t) • t=0: g(0)=1（瞬間通過） • t=τ: g(τ)=e⁻¹≈0.368 • t→∞: g(∞)=0（直流完全衰減） g_LPF(t)+g_HPF(t)=1

時域分析 — 等價實現

y(t)=x(t)-(1/τ)·∫₀^t x(τ')·e^(-(t-τ')/τ)dτ' = x(t) - y_LPF(t) // HPF = 原始訊號 - LPF輸出，有時比直接HPF更數值穩定

離散時域 — 差分方程

y[n]=α·(y[n-1]+x[n]-x[n-1]) α=τ/(τ+Ts)=1/(1+ωc·Ts) y[n]=α·y[n-1]+α·x[n]-α·x[n-1] 驗證直流: x[n]=C → y[n]=α·y[n-1] → y[n]→0 ✓
飛控應用：加速度計測量值 x[n] 含重力（低頻恆定）與動態加速度（高頻）。HPF輸出中重力被指數衰減至零，僅保留動態加速度瞬間變化。

陷波濾波器（Notch Filter）

頻域分析

連續時間傳遞函數: H(s) = (s²+ω₀²)/(s²+(ω₀/Q)s+ω₀²) 其中 ω₀=2π·f₀ 為中心角頻率，Q 為品質因數。Q 值越高，陷波越窄越深。 頻率響應幅度: |H(jω)| = |ω₀²-ω²| / √[(ω₀²-ω²)²+(ω₀ω/Q)²] • ω=0: |H|=1 (0 dB) • ω=ω₀: |H|=0 (-∞ dB，完全衰減) • ω→∞: |H|→1 (0 dB) -3 dB 帶寬: BW = ω₀/Q (rad/s) 或 BW = f₀/Q (Hz) 相位響應: ∠H(jω) = -arctan[(ω₀ω/Q)/(ω₀²-ω²)] • ω<ω₀: 相位接近 0° • ω=ω₀: 相位跳變（理論上從 +90° 跳到 -90°） • ω>ω₀: 相位接近 -180° 高 Q 值的代價：相位在 ω₀ 附近變化極快，導致群延遲劇增。 群延遲 τg(ω) 在 ω=ω₀ 處達到最大值，與 Q 成正比。

時域分析 — 微分方程

d²y/dt²+(ω₀/Q)·dy/dt+ω₀²·y = d²x/dt²+ω₀²·x // 右邊同時出現x的二階導數和x本身

時域分析 — 脈衝響應（高Q值）

H(s)=1-[(ω₀/Q)s]/[s²+(ω₀/Q)s+ω₀²] h(t)=δ(t)-(ω₀/Q)·e^(-ω₀t/(2Q))·[cos(ωd·t)-(ω₀/(2Qωd))·sin(ωd·t)]·u(t) ωd≈ω₀ (當Q>>1) // 瞬間衝擊通過 + 阻尼振盪尾（中心頻率≈ω₀） // 振盪尾「抵消」持續時間為2π/ω₀的輸入成分

時域分析 — 對正弦輸入 x(t)=sin(ω₀t) 的響應

d²x/dt²=-ω₀²·sin(ω₀t)=-ω₀²·x → d²x/dt²+ω₀²·x=0 方程變為齊次: d²y/dt²+(ω₀/Q)·dy/dt+ω₀²·y=0 穩態: y_ss(t)=0 // 完美驗證：ω₀頻率正弦被完全衰減！ // 瞬態呈現指數衰減振盪，時間常數≈2Q/ω₀

時域分析 — 脈衝響應「記憶長度」與 Q 值

衰減時間常數: τ_decay=2Q/ω₀=Q/(π·f₀) • Q=2, f₀=200Hz: τ≈3.2ms (~25個8kHz取樣點) • Q=5, f₀=200Hz: τ≈8.0ms (~64個取樣點) • Q=10, f₀=200Hz: τ≈15.9ms (~127個取樣點) // 高Q陷波引入顯著時域記憶/相位延遲 // 飛控權衡: 高Q頻域精準但時域延遲大；低Q頻域較寬但延遲小

離散時域 — BiQuad 實現

y[n]=b0·x[n]+b1·x[n-1]+b2·x[n-2]-a1·y[n-1]-a2·y[n-2] 雙線性變換係數（Tustin 法）: K=tan(π·f₀/fs), K2=K², D=1+K/Q+K2 b0=(1+K2)/D, b1=2·(K2-1)/D, b2=b0 a1=b1, a2=(1-K/Q+K2)/D // 陷波對稱性 b0=b2 確保: // • 直流增益=1 • 奈奎斯特增益=1 • 僅ω₀處增益=0
高Q的時域代價：Betaflight建議Q≤250（動態陷波寬版）或Q≤5（靜態陷波）。過高Q使脈衝響應振盪尾過長，快速機動時產生可感知控制延遲。

動態陷波濾波器（Dynamic Notch）

頻域分析

現代飛控面臨的挑戰：馬達轉速隨油門變化，導致共振頻率漂移。 Betaflight 4.0+ 引入動態陷波濾波器: f_notch(t) = k · RPM(t)/60 · N_blades • k: 諧波次數（通常為 1 或 2） • RPM(t): 即時馬達轉速（由 DShot 回傳或油門估算） • N_blades: 螺旋槳葉片數 動態陷波會根據即時轉速調整中心頻率 f₀，確保共振頻率始終位於陷波中心。 時變傳遞函數: H(s,t) = (s²+ω₀(t)²)/(s²+(ω₀(t)/Q)s+ω₀(t)²)

時域分析 — 時變系統行為

d²y/dt²+(ω₀(t)/Q)·dy/dt+ω₀(t)²·y = d²x/dt²+ω₀(t)²·x ω₀(t)=2π·k·RPM(t)/60·N_blades // 時變系統，準靜態近似成立 // RPM變化率<100Hz/s << 系統響應時間~10ms

互補濾波器（Complementary Filter）

頻域分析

核心思想：融合兩個感測器的優勢 • 陀螺儀（Gyro）：高頻響應好，但低頻有漂移（積分誤差累積） • 加速度計（Accel）：低頻準確（可測重力方向），但高頻受振動干擾 頻域分解原理: 設真實姿態角為 θ(t)，可分解為低頻與高頻成分: θ(t) = θ_LF(t) + θ_HF(t) 陀螺儀測量: θ_gyro(t) = θ_HF(t) + drift(t) ← 高頻準確 加速度計測量: θ_accel(t) = θ_LF(t) + noise(t) ← 低頻準確 一階互補濾波器: θ̂(s) = G_LPF(s)·θ_accel(s) + G_HPF(s)·θ_gyro(s) 其中: G_LPF(s) = α/(s+α) （低通通路） G_HPF(s) = s/(s+α) （高通通路） 且滿足互補條件: G_LPF(s) + G_HPF(s) = 1 頻率響應特性: • 低頻 (ω<<α): 主要信任加速度計（G_LPF≈1, G_HPF≈0） • 高頻 (ω>>α): 主要信任陀螺儀（G_LPF≈0, G_HPF≈1） • 交叉頻率 ω=α: 兩者權重相等（各 0.5 幅度，-3 dB） α = 1/τ，τ 為時間常數（通常 0.5~2 秒） 對應交叉頻率 fc = α/(2π) = 1/(2πτ)（通常 0.1~0.5 Hz）

時域分析 — 連續時間推導

由頻域出發，取反拉氏變換: dθ̂/dt = ω_gyro + α·(θ_accel - θ̂) // 陀螺儀積分預測 + 加速度計誤差修正

時域分析 — 誤差動態

e(t)=θ_true-θ̂ 假設: ω_gyro=ω_true+b_gyro, θ_accel=θ_true+n_accel de/dt + α·e = -b_gyro - α·n_accel // 誤差以時間常數τ=1/α指數收斂 // 陀螺儀漂移導致穩態誤差: e_ss=-b_gyro/α // 這是一階互補的根本限制！

離散時域遞迴式

θ̂[n]=θ̂[n-1]+Ts·ω_gyro[n]+γ·(θ_accel[n]-θ̂[n-1]-Ts·ω_gyro[n]) γ=α·Ts=Ts/(τ+Ts) 等價寫法: θ̂[n]=(1-γ)·(θ̂[n-1]+Ts·ω_gyro[n])+γ·θ_accel[n] // (1-γ)·陀螺儀積分預測 + γ·加速度計修正

二階互補濾波器（Madgwick / Mahony）

頻域分析

為了消除陀螺儀漂移，引入漂移估計狀態 b̂(t)。 從頻域觀點，這相當於在互補濾波器中加入一個積分器， 形成二階系統，可完全抑制直流（零頻）漂移。 誤差傳遞函數從一階: E(s)/B_gyro(s) = -1/(s+α) 變為二階: E(s)/B_gyro(s) = -s/(s²+Kp·s+Ki) 穩態誤差（終值定理）: e_ss = lim_{s→0} s·[-s/(s²+Kp·s+Ki)]·(b_gyro/s) = 0 // 二階系統對恆定漂移的穩態誤差為零！

時域分析 — PI 控制結構

狀態擴展: [θ̂(t), b̂(t)]ᵀ dθ̂/dt = ω_gyro - b̂ + Kp·(θ_accel - θ̂) db̂/dt = Ki·(θ_accel - θ̂) 誤差動態特徵方程: s²+Kp·s+Ki=0 選擇 Kp=2ζωn, Ki=ωn² • Mahony: Kp=2·Kp_gain, Ki=Kp_gain² • 典型 Kp_gain: 0.5~5.0

Madgwick 濾波器時域形式

四元數更新: dq/dt=½·q⊗(ω_gyro-b̂)+β·∇f(q,a,m) db̂/dt=-ζ·(ω_gyro-b̂)×(∇f的角速度誤差分量) • β: 收斂速率（感測器信任度） • ζ: 漂移學習速率 • ∇f: 加速度計/磁力計測量誤差梯度 // 梯度下降優化 + 陀螺儀積分的混合系統

擴展卡爾曼濾波器（EKF）

頻域分析

EKF 本質上是一個時變線性系統，其等價頻域特性由當前工作點的線性化決定。 在穩態附近（小擾動假設），EKF 的行為可近似為一個時變濾波器: H_EKF(s,t) ≈ C(t)·[sI-A(t)]⁻¹·B(t) + D(t) 其中 A(t), B(t), C(t), D(t) 由當前狀態的 Jacobian 決定。 與固定係數濾波器（LPF/Notch）的區別: • 固定濾波器: H(s) 不隨時間變化，頻率響應固定 • EKF: 等價 H(s,t) 隨狀態與協方差演化，自適應調整頻率響應 具體而言，卡爾曼增益 Kₖ 決定了等價頻寬: • K 大（信任觀測）→ 等價頻寬寬 → 響應快但對雜訊敏感 • K 小（信任預測）→ 等價頻寬窄 → 響應慢但雜訊免疫 這種「自適應頻寬」是 EKF 相較於固定濾波器的核心優勢: 飛行平穩時（觀測可靠）自動展寬頻寬，劇烈機動時（觀測雜訊大）自動縮窄頻寬。

時域分析 — 連續狀態空間

狀態向量: x(t)=[q₀,q₁,q₂,q₃,b_x,b_y,b_z]ᵀ dx(t)/dt = f(x(t),u(t)) + w(t) 四元數運動學: dq/dt=½·Ω(ω)·q Ω(ω)=[0,-ωx,-ωy,-ωz; ωx,0,ωz,-ωy; ωy,-ωz,0,ωx; ωz,ωy,-ωx,0] 陀螺儀偏差（隨機遊走）: db/dt=w_b(t), w_b~N(0,σ_b²)

時域分析 — 離散狀態空間

xₖ=xₖ₋₁+Ts·f(xₖ₋₁,uₖ₋₁)+wₖ₋₁ zₖ=h(xₖ)+vₖ zₖ=[a_x,a_y,a_z,m_x,m_y,m_z]ᵀ: 加速度計+磁力計 h(xₖ): 姿態→預測重力方向與磁場方向 vₖ~N(0,R): 觀測雜訊

時域分析 — 預測步驟

x̂ₖ|ₖ₋₁=x̂ₖ₋₁|ₖ₋₁+Ts·f(x̂ₖ₋₁|ₖ₋₁,uₖ₋₁) Pₖ|ₖ₋₁=Fₖ₋₁·Pₖ₋₁|ₖ₋₁·Fₖ₋₁ᵀ+Q Fₖ₋₁=I+Ts·(∂f/∂x)|_(x̂ₖ₋₁|ₖ₋₁) // 開環積分預測：陀螺儀角速度→姿態積分 // P因過程雜訊Q而增大（預測不確定性增加）

時域分析 — 更新步驟

創新（殘差）: ỹₖ=zₖ-h(x̂ₖ|ₖ₋₁) 卡爾曼增益: Kₖ=Pₖ|ₖ₋₁·Hₖᵀ·(Hₖ·Pₖ|ₖ₋₁·Hₖᵀ+R)⁻¹ 狀態更新: x̂ₖ|ₖ=x̂ₖ|ₖ₋₁+Kₖ·ỹₖ 協方差更新: Pₖ|ₖ=(I-Kₖ·Hₖ)·Pₖ|ₖ₋₁

時域分析 — 卡爾曼增益極限

R→0 (觀測極精準): K→H⁺ → 完全信任觀測 R→∞ (觀測極雜訊): K→0 → 完全忽略觀測（純開環） P→∞ (預測極不確定): K→H⁺ → 依賴觀測 EKF自動實現「預測-觀測」信任權衡，無需手動調整增益
時域優勢：EKF同時估計姿態和陀螺儀漂移，通過P矩陣演化自適應調整K增益。無GPS時P增大自動降低預測信任；GPS恢復時大創新ỹ通過K快速修正累積誤差。

核心 C 語言時域實現

1. PT1 濾波器 — 時域遞迴

typedef struct { float k; // α = Ts/(τ+Ts) float state; // y[n-1] } pt1Filter_t; float pt1FilterApply(pt1Filter_t *f, float input) { // y[n] = α·x[n] + (1-α)·y[n-1] // 等價增量形式（更數值穩定）: f->state = f->state + f->k * (input - f->state); return f->state; } void pt1FilterInit(pt1Filter_t *f, float fc, float fs) { float rc = 1.0f / (2.0f * M_PIf * fc); float dt = 1.0f / fs; f->k = dt / (rc + dt); // α = Ts/(τ+Ts) f->state = 0.0f; }

2. BiQuad 濾波器 — 時域遞迴

typedef struct { float b0, b1, b2; // 分子係數 float a1, a2; // 分母係數（a0=1） float x1, x2; // x[n-1], x[n-2] float y1, y2; // y[n-1], y[n-2] } biquadFilter_t; float biquadFilterApply(biquadFilter_t *f, float input) { float result = f->b0*input + f->b1*f->x1 + f->b2*f->x2 - f->a1*f->y1 - f->a2*f->y2; f->x2 = f->x1; f->x1 = input; f->y2 = f->y1; f->y1 = result; return result; } // 直接對應: y[n]=b0·x[n]+b1·x[n-1]+b2·x[n-2]-a1·y[n-1]-a2·y[n-2]

3. 陷波濾波器係數計算

void biquadFilterInitNotch(biquadFilter_t *f, float fs, float f0, float Q) { float K = tanf(M_PIf * f0 / fs); float K2 = K * K; float invD = 1.0f / (1.0f + K / Q + K2); f->b0 = (1.0f + K2) * invD; f->b1 = 2.0f * (K2 - 1.0f) * invD; f->b2 = f->b0; // 陷波對稱性: b0=b2 f->a1 = f->b1; // a1 = b1 f->a2 = (1.0f - K/Q + K2) * invD; f->x1 = f->x2 = f->y1 = f->y2 = 0.0f; } // 雙線性變換: s=(2/Ts)·(1-z⁻¹)/(1+z⁻¹) 的實現

實務配置範例（5吋競速機）

以下為典型的 Betaflight 4.4+ 濾波器配置，適用於 5 吋 FPV 競速無人機（2306 馬達 + 5 吋三葉槳）：

# === 陀螺儀濾波 === set gyro_lpf1_type = PT2 set gyro_lpf1_static_hz = 250 set gyro_lpf2_type = PT1 set gyro_lpf2_static_hz = 500 # === 動態陷波濾波器 === set dyn_notch_count = 2 set dyn_notch_q = 120 set dyn_notch_min_hz = 100 set dyn_notch_max_hz = 600 # === D-term 濾波 === set dterm_lpf1_type = PT1 set dterm_lpf1_static_hz = 100 set dterm_lpf2_type = PT1 set dterm_lpf2_static_hz = 200 # === 馬達濾波（RPM Filter）=== set dshot_bidir = ON set rpm_filter_harmonics = 3 set rpm_filter_min_hz = 20 set rpm_filter_fade_range_hz = 50
參數調整原則：
1. 先用 Blackbox 記錄陀螺儀原始數據，FFT 分析找出共振峰
2. 設置 Notch Filter 對準共振頻率
3. LPF 截止頻率盡量設高（減少相位延遲），但必須確保共振峰被衰減至安全範圍
4. D-term LPF 通常比 Gyro LPF 更嚴格，因為微分運算會放大高頻

RPM 濾波器原理（DShot 雙向通訊）

Betaflight 4.0+ 支援 DShot 雙向協議，ESC 回傳每個馬達的即時轉速（eRPM）。RPM 濾波器為每個馬達建立獨立的動態陷波：

f_notch_i(t) = eRPM_i(t) / (60 × N_poles) × k_harmonic 其中: • eRPM_i: 第 i 個馬達的電子轉速（DShot 回傳） • N_poles: 馬達磁極對數（通常 7 對 = 14 極） • k_harmonic: 諧波次數（1, 2, 3...） 每個馬達產生 3 個諧波陷波 × 4 個馬達 = 最多 12 個動態陷波濾波器 時域行為: // 每個取樣週期根據最新 eRPM 重新計算 BiQuad 係數 // 係數更新速率與 DShot 回傳速率一致（通常與 PID 迴路同頻） // 馬達轉速變化時，陷波中心頻率平滑跟隨
優勢：RPM Filter 只衰減與馬達轉速相關的窄帶噪音，對其他頻率幾乎無影響。相比傳統寬帶 LPF，相位延遲顯著降低，飛行手感更「跟手」。

濾波器對 PID 控制的時域影響

濾波器參數相位延遲時域響應風險

Gyro LPF >500Hz小 (~0.3ms)階躍響應靈敏可能放大共振
