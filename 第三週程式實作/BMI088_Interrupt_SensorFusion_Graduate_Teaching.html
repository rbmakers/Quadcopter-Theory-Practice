01　從「讀到數字」走向「可信的姿態」

本教材以 CURIO／RP2354A、Arduino IDE、BMI088 I²C 為案例，串接量測原理、暫存器、即時程式與姿態估測。建議安排兩次 3 小時課程：第一次完成資料取得與時序量測，第二次推導融合與分析誤差。先備知識為 C/C++、微積分、向量叉積、離散取樣與基本回授控制。

資料取得

分辨輪詢、DRDY 中斷與硬體資料同步，理解重複樣本、漏樣與讀取跨界。

量測品質

由 full scale 推導 LSB，區分解析度、重複性、偏差、延遲與準確度。

姿態融合

從 quaternion 運動學推導 Mahony 回授與 Madgwick 梯度修正，判讀三軸曲線。

核心結論：中斷改善通知與排程；同步改善兩顆感測器的時間對齊；融合改善姿態估測。這三件事各自解決不同問題，沒有任何一個「精度暫存器」能直接保證姿態誤差為 ±0.1°。

範圍：感測器與姿態教學，不包含馬達控制。本教材核對已交付的 Fusion v1.0 與 BMI088 v1.2 驅動。可取得的早期附件現已是中斷版，因此輪詢章節採「原始不使用中斷之架構的教學重建」，不宣稱是最初附件的逐字原碼。程式節錄用於解說；完整可編譯融合專案見第 18 節。

04　I²C 讀取、位元組組合與失敗處理

典型 burst read 先寫入起始暫存器位址，再以 repeated START 切到讀取。每個位元組含 8 data bits 與第 9 個 ACK/NACK clock。ACK 只表示傳輸階段的回應，不代表量測正確或新鮮。

// 教學用共用片段：需 #include <Wire.h>，並先完成 Wire 初始化。
bool readRegs(uint8_t dev, uint8_t reg, uint8_t *out, size_t n) {
    if (!out || n == 0 || n > 32) return false;
    uint8_t tmp[32];
    Wire.beginTransmission(dev);
    if (Wire.write(reg) != 1) { Wire.endTransmission(); return false; }
    if (Wire.endTransmission(false) != 0) return false;
    size_t got = Wire.requestFrom(dev, n, true);
    if (got != n || Wire.available() < (int)n) {
        while (Wire.available()) Wire.read();
        return false;
    }
    for (size_t i=0; i<n; ++i) tmp[i] = (uint8_t)Wire.read();
    for (size_t i=0; i<n; ++i) out[i] = tmp[i];
    return true; // 完整成功才發布；失敗時 out 保持原狀
}
int16_t decodeLE(const uint8_t *p) {
    uint16_t u = uint16_t(p[0]) | (uint16_t(p[1]) << 8);
    return (u & 0x8000) ? int16_t(int32_t(u)-65536) : int16_t(u);
}

c 為 signed 16-bit raw count；Rₐ 為正向滿量程數值（例如 6 g 的 6）；Rɡ 例如 2000 °/s；g₀=9.80665 m/s²。上式 ω 單位為 °/s，融合前再乘 π/180。

05　不使用 Interrupt：輪詢架構的教學重建

最簡單的方法是由 loop 決定何時讀取普通資料暫存器。以下假設已完成一般模式初始化：Accel 啟用、Gyro normal、量程 ±6 g／±2000 °/s、一般 ODR／BW 已設定，且沒有開啟同步 feature。此片段用於比較讀取架構，不是可直接上傳的完整初始化程式。

// 接續第 4 節共用函式；一般 raw-data 路徑。
struct Sample { float ax,ay,az,gx,gy,gz; };
bool readOrdinary(Sample &out) {
    uint8_t a[6], g[6];
    if (!readRegs(0x18, 0x12, a, 6)) return false;
    if (!readRegs(0x69, 0x02, g, 6)) return false;
    const float sa = 6.0f * 9.80665f / 32768.0f;
    const float sg = 2000.0f / 32768.0f;
    Sample next{decodeLE(a)*sa, decodeLE(a+2)*sa, decodeLE(a+4)*sa,
                decodeLE(g)*sg, decodeLE(g+2)*sg, decodeLE(g+4)*sg};
    out=next;
    return true;
}
void loop() {
    static uint32_t lastUs=0;
    uint32_t now=micros();
    if (uint32_t(now-lastUs)<2500) return; // 約 400 Hz 排程
    lastUs=now;
    Sample s;
    if (!readOrdinary(s)) return;
    // s 是這次成功讀到的值，但沒有證明兩顆晶片同時取樣。
    // 顯示應降頻；不可在每次讀取後長時間 Serial.print / delay。
}

輪詢 DRDY 狀態位可觀察資料就緒，不必接 MCU 中斷增加 I²C 交易；狀態清除條件需查手冊；不是資料配對 FIFO
以 GPIO digitalRead 輪詢 DRDY不用 I²C 讀狀態CPU 必須及時看見脈衝；太慢仍可能漏事件

若在 loop 末尾加入 delay(1)，實際週期是「程式執行時間 + 至少 1 ms」，並非固定 1 ms。輪詢不是必然不好：低速展示與初始化偵錯很合適；對控制系統，必須量測資料新鮮度與延遲。

06　使用 Interrupt：先讓新資料通知 MCU

中斷版把「何時處理」改為事件觸發。資料仍透過 I²C 讀回；中斷腳不會把三軸數值傳給 MCU。一般 DRDY 版與同步 DRDY 版是兩個不同層次。

模式Accel 中斷來源讀取 Accel保證程度
一般 DRDY IRQ普通加速度資料就緒，0x58 bit2 → INT10x12～0x17有新資料通知；不保證與 Gyro 同一物理時間
Bosch 同步 IRQ同步 feature 完成通知，API 配置0x1E～0x21 與 0x27～0x28經配置的感測器時間對齊；仍要確保主機讀取不跨更新
volatile uint32_t accEvents=0, accEdgeUs=0;
void onAccReady() {
    accEdgeUs = time_us_32();
    ++accEvents; // ISR 僅做快速工作，不進行 Wire 或 Serial
}
// setup：pinMode(22, INPUT);
// attachInterrupt(digitalPinToInterrupt(22), onAccReady, RISING);

// 同一核心原子快照：不能讓 ISR 在讀取 count 與 timestamp 中間更新。
uint32_t irqState=save_and_disable_interrupts();
uint32_t n=accEvents, edge=accEdgeUs;
restore_interrupts(irqState);

volatile 使共享值按要求被讀寫，但不等於跨核心同步，也不會把 count 與 timestamp 變成一組不可分割的操作。此處短暫關閉同核心中斷，是為了取得一致快照；不要在整段 I²C 交易期間關閉中斷。

單一 bool ready 會把多次事件合併成一次。計數器可偵測跳過幾個事件，但不能還原已被最新資料覆蓋的樣本。若要保留歷史樣本，需要正確使用 FIFO 與時間資訊，而不是多次重讀同一組輸出暫存器。

07　INT3 接 INT2：真正的資料同步

08　1 kHz 的時間預算與跨樣本防護

每次 n-byte 隨機讀取約含三個前置位元組：address+W、register、address+R；再加 n 個 data bytes。忽略 START/STOP、軟體與等待開銷，可得理論匯流排時間下限：

Tbus,min=9∑i(ni+3)fSCL=9[(4+3)+(2+3)+(6+3)]400000=472.5 μsT_{\mathrm{bus,min}}=\frac{9\sum_i(n_i+3)}{f_{\mathrm{SCL}}}=\frac{9[(4+3)+(2+3)+(6+3)]}{400000}=472.5\ \mu\mathrm{s}

此為三次同步讀取的推算下限，不是實測時間；不能拿來保證 deadline。

Tservice+Tread+Tfusion+Tother<TsT_{\mathrm{service}}+T_{\mathrm{read}}+T_{\mathrm{fusion}}+T_{\mathrm{other}}<T_s

service 為就緒到開始服務的等待；read 是匯流排與驅動成本；fusion 是兩套算法；other 包含 ISR 與其他干擾。各項最壞時間還要留餘裕。

互動：匯流排下限與實測餘裕

2000 Hz 選項僅用於預算分析，不代表目前驅動已支援。602 µs 為先前純感測器測試案例，並非融合版已量測值。

現有 loop 的接受條件：開始服務距 INT1 不超過週期的 1/4；讀取前後 Accel 與 Gyro 的 IRQ 計數不能改變；完成讀取時仍在本週期內。1 kHz 時門檻分別是 250 µs 與 1000 µs。這是保守的軟體檢查，不是硬體多暫存器原子讀取保證；ISR 延遲、長時間關中斷仍可能影響判定。

12　濾波、雜訊與控制延遲的代價

σ≈ndBENBW,σxˉ≈σN\sigma\approx n_d\sqrt{B_{\mathrm{ENBW}}},\qquad \sigma_{\bar x}\approx\frac{\sigma}{\sqrt{N}}

n_d：雜訊密度；B_ENBW：等效雜訊頻寬，不一定等於 -3 dB 頻寬。第二式只適用於近似獨立、零均值樣本；低通後的相鄰樣本通常相關。

以理想白雜訊示例，取 nₐ=175 µg/√Hz、nɡ=0.014 °/s/√Hz，若 ENBW=100 Hz，則 σₐ≈1.75 mg、σɡ≈0.14 °/s。數值用於解釋量綱；實機需依測試條件、濾波響應、安裝與溫度量測，不能把產品典型密度當作全條件保證。[4]

第一式是教學用一階低通，τ=1/(2πf_c)。第二式是純延遲造成的相位；不能用它取代完整濾波器頻率響應。

降低頻寬常能讓曲線更平順，同時增加對快速運動的延遲。若控制迴路在 20 Hz 附近有重要動態，單是 2.5 ms 純延遲就相當於 18° 相位落後。這也解釋了為何高頻更新的飛控仍須重視感測器群延遲。

混疊一旦發生，後面的數位低通無法恢復原始頻率。50 Hz 的顯示降採樣也不是抗混疊處理；現有 Plotter 輸出僅適合觀察緩慢姿態，不應拿來分析馬達高頻震動。要做頻譜實驗，需保存足夠速率的原始資料，並在降採樣前設計低通。

13　校正與座標：融合之前先把物理量弄對

15　Mahony：用方向誤差回授修正角速度

Mahony 方法可從非線性互補觀測器理解。本教材對應目前程式的六軸 quaternion 實作：以量測方向與預測方向的叉積建立修正，不在 Euler 角上直接做三個獨立平均。下列是本實作的記號，增益定義可能與使用 twoKp／half-vector 的函式庫不同。[5]

u=a∥a∥,e=u×v^\mathbf u=\frac{\mathbf a}{\|\mathbf a\|},\qquad \mathbf e=\mathbf u\times\hat{\mathbf v}

u：實測比力方向；v̂：quaternion 預測方向；e：向量方向誤差。叉積順序反轉，回授符號就相反。

Ik+1=clip⁡(Ik+KiekΔtk),ωcorr=ωc+Kpek+Ik+1\mathbf I_{k+1}=\operatorname{clip}(\mathbf I_k+K_i\mathbf e_k\Delta t_k),\qquad \boldsymbol\omega_{\mathrm{corr}}=\boldsymbol\omega_c+K_p\mathbf e_k+\mathbf I_{k+1}

I 是本程式加到角速度上的積分修正，等價於對剩餘 bias 的負向補償。Kp 單位 s⁻¹、Ki 單位 s⁻²（rad 視為無因次）；I 為 rad/s。

q˙=12q⊗[0,ωcorr]T\dot q=\frac12q\otimes[0,\boldsymbol\omega_{\mathrm{corr}}]^T
  1. 確認 dt 與 Gyro 有效，先扣開機估計零偏並換為 rad/s。
  2. 若 Accel 可信，正規化並計算 e。
  3. 依 Ki 更新積分修正，加入 Kp·e；若不信任 Accel，略過本次方向修正。
  4. 以修正角速度積分 q，再正規化。

本例 kp=2.0、ki=0.0，因此沒有啟用在線積分偏差估測，仍有開機 Gyro 零偏校正。若開啟 Ki，程式每軸 I 限制在 ±0.2 rad/s；此為軟體保護值，不是量測量程。

θ~¨+Kpθ~˙+Kiθ~≈0,ωn=Ki,ζ=Kp2Ki\ddot{\tilde\theta}+K_p\dot{\tilde\theta}+K_i\tilde\theta\approx0,\qquad \omega_n=\sqrt{K_i},\quad \zeta=\frac{K_p}{2\sqrt{K_i}}

此為靜止、小傾角、單一可觀測傾角通道、連續時間、未飽和時的局部模型；不是完整三維全域系統，也不能拿來宣稱 Yaw 已可觀測。Ki=0 時不可使用右側 ζ 公式；傾角誤差近似一階回復。

提高 Kp 會加強傾角修正，也更容易把持續線性加速度誤當成傾斜。Ki 過大或在錯誤重力觀測下累積，會形成不良偏差補償。應先驗證資料與開機校正，再調參。

madgwick.update(gx,gy,gz,s.ax,s.ay,s.az,dt,useAccel);

0.75g～1.25g 是本例的加速度可信度門檻，不是完整運動分類器。例如水平加速 0.2g 時，合向量大小只有約 1.02g，仍會通過門檻，但方向已偏轉約 11.3°。因此通過門檻不代表比力方向必然等於重力方向。

若相隔 2 ms 才收到下一筆，程式以 2 ms 積分當前角速度，屬於對未知中間運動的近似；不能稱為補回遺失樣本。超過 20 ms 時保留原姿態但跳過積分，姿態可能已過時；重新取得資料後也不會神奇恢復中斷期間的 Yaw。

19　五個循序實驗與量化評分

實驗控制變因與步驟應交付的證據
A：輪詢 vs 中斷固定量程／BW／資料率；比較定時輪詢與 DRDY 事件版。再加入低頻 Serial 工作觀察干擾IRQ 到讀取的延遲分布、成功率、最大讀取時間；不可只比較 Serial 行數
B：一般 IRQ vs 同步 IRQ同一硬體、同一運動，比較普通資料路徑與 Bosch 同步路徑。先確認兩者 register 與接線一致邏輯分析儀 INT1/INT3/SCL；清楚區分時間配對與 I²C 完成時間
C：量程與靜止雜訊固定 ODR/BW、溫度與安裝，逐一改量程並同步更新轉換比例；每組收集至少 30 秒raw 與物理單位 std、均值、接近滿刻度比例；不得把 LSB 細化當準確度證明
D：兩套融合與增益同一時間戳資料重播，先比較預設，再一次只改 Kp 或 β；用固定角度治具測試靜態 bias、std、動態延遲、回復時間、已知角度誤差；不可用兩套互相比當真值
E：Yaw 漂移與線性加速度靜止 60 秒、繞 Z 軸轉回原位、平移但保持水平；分別記錄結果Yaw 漂移 °/min、回零誤差、平移造成的假傾角；說明可觀測性限制
bias=1N∑k(θ^k−θref,k),RMSE=1N∑k(θ^k−θref,k)2\mathrm{bias}=\frac1N\sum_k(\hat\theta_k-\theta_{\mathrm{ref},k}),\quad \mathrm{RMSE}=\sqrt{\frac1N\sum_k(\hat\theta_k-\theta_{\mathrm{ref},k})^2}

θref 應來自獨立參考。跨越 ±180° 時先用 circular angle difference，不能直接把 179° 與 −179° 的差判為 358°。動態測試需對齊時間，並另外報告延遲。

eangle=atan2⁡(sin⁡(θ^−θref),cos⁡(θ^−θref))e_{\mathrm{angle}}=\operatorname{atan2}(\sin(\hat\theta-\theta_{\mathrm{ref}}),\cos(\hat\theta-\theta_{\mathrm{ref}}))

單軸循環角度誤差，上式用 rad；若評估完整 3D 姿態，宜以 quaternion 相對旋轉角衡量，避免 Euler 奇異性。

eR=2arccos⁡(clip⁡(∣qrefTq^∣,0,1))e_R=2\arccos\bigl(\operatorname{clip}(|q_{\mathrm{ref}}^T\hat q|,0,1)\bigr)

qref 與 q̂ 必須都正規化、使用相同 quaternion 順序與座標慣例；絕對值處理 q 與 −q 的等價性。

建議評分：資料品質與錯誤處理 25%、時序量測 25%、融合推導與單位正確 25%、獨立參考驗證及限制說明 25%。圖形平滑只是觀察之一，不能取代這些指標。

20　課堂討論與參考答案

中斷每秒 1000 次，是否表示取得 1000 筆有效配對？

否。IRQ 事件、I²C 成功、未跨更新、融合接受是不同關卡。必須比較各階段計數。

將 I²C 設成 1 MHz 能否改善 1 kHz 同步讀取？

本例 BMI088 I²C 規格最大 400 kHz，不應以超規時脈當修正。可改善排程、減少交易；更高吞吐需求評估 SPI。

改為 ±3 g，是否角度準確度一定提高一倍？

否。理論 LSB 階距減半，但偏差、類比雜訊、動態加速度與校正誤差不會自動減半，也更容易飽和。

加速度計為何不能直接求 Yaw？

單一重力方向只提供兩個獨立方向約束；繞該方向旋轉無法從此觀測分辨。

將 dt 永遠寫成 0.001 有何風險？

漏樣或抖動時，積分角度與實際時間不符。應使用成功樣本時間戳，並定義過大間隔的處置。

0x58 沒有普通 DRDY 映射，為何 INT1 仍有事件？

同步版由 feature 的同步完成事件映射到 INT1，不是普通 Accel DRDY。需看同步 API 與對應 feature 設定。

兩套算法曲線很接近，是否已證明準確？

否。它們共用相同資料、零偏與軸映射，可能有共同誤差。仍需獨立參考。

Serial Plotter 的 ±180° 跳變是否一定是數值發散？

不一定。先檢查角度 wrap 與 quaternion 範數，再檢查單位、dt、資料失敗與軸映射。

// Independent equation-based implementations. Units: rad/s, arbitrary accel
// units, seconds. Quaternion rotates sensor vectors into the reference frame.
namespace Fusion6D {
constexpr float PI_F=3.14159265358979323846f;
constexpr float RAD=PI_F/180.0f, DEG=180.0f/PI_F;
struct Euler { float roll, pitch, yaw; };
struct Quaternion {
    float w=1, x=0, y=0, z=0;
    void normalize() {
        float n=sqrtf(w*w+x*x+y*y+z*z);
        if (isfinite(n) && n>1e-12f) { w/=n; x/=n; y/=n; z/=n; }
        else { w=1; x=y=z=0; }
    }
    void fromAccel(float ax,float ay,float az) {
        float r=atan2f(ay,az), p=atan2f(-ax,sqrtf(ay*ay+az*az));
        float cr=cosf(r/2),sr=sinf(r/2),cp=cosf(p/2),sp=sinf(p/2);
        w=cr*cp; x=sr*cp; y=cr*sp; z=-sr*sp; normalize();
    }
    Euler euler() const {
        float s=2*(w*y-z*x); s=fmaxf(-1,fminf(1,s));
        return {DEG*atan2f(2*(w*x+y*z),1-2*(x*x+y*y)),
                DEG*asinf(s),DEG*atan2f(2*(w*z+x*y),1-2*(y*y+z*z))};
    }
    void integrate(float gx,float gy,float gz,float dt,
                   float sw=0,float sx=0,float sy=0,float sz=0) {
        float dw=0.5f*(-x*gx-y*gy-z*gz)-sw;
        float dx=0.5f*(w*gx+y*gz-z*gy)-sx;
        float dy=0.5f*(w*gy-x*gz+z*gx)-sy;
        float dz=0.5f*(w*gz+x*gy-y*gx)-sz;
        w+=dt*dw; x+=dt*dx; y+=dt*dy; z+=dt*dz; normalize();
    }
};
inline bool validStep(float gx,float gy,float gz,float dt) {
    return isfinite(gx)&&isfinite(gy)&&isfinite(gz)&&isfinite(dt)&&dt>0&&dt<=0.02f;
}
inline bool unitAccel(float &ax,float &ay,float &az) {
    float n=sqrtf(ax*ax+ay*ay+az*az);
    if (!isfinite(n)||n<1e-6f) return false;
    ax/=n; ay/=n; az/=n; return true;
}
class Mahony {
public:
    Quaternion q;
    float kp=2.0f,ki=0.0f;
    void reset(float ax,float ay,float az) {q.fromAccel(ax,ay,az); ix=iy=iz=0;}
    bool update(float gx,float gy,float gz,float ax,float ay,float az,float dt,bool useAccel=true) {
        if (!validStep(gx,gy,gz,dt)) return false;
        if (ki<=0) ix=iy=iz=0;
        if (useAccel && unitAccel(ax,ay,az)) {
            float vx=2*(q.x*q.z-q.w*q.y),vy=2*(q.w*q.x+q.y*q.z);
            float vz=1-2*(q.x*q.x+q.y*q.y);
            float ex=ay*vz-az*vy,ey=az*vx-ax*vz,ez=ax*vy-ay*vx;
            if(ki>0) {ix=limit(ix+ki*ex*dt);iy=limit(iy+ki*ey*dt);iz=limit(iz+ki*ez*dt);}
            gx+=kp*ex; gy+=kp*ey; gz+=kp*ez;
        }
        q.integrate(gx+ix,gy+iy,gz+iz,dt); return true;
    }
private:
    float ix=0,iy=0,iz=0;
    static float limit(float x) {return fmaxf(-0.2f,fminf(0.2f,x));}
};
class Madgwick {
public:
    Quaternion q;
    float beta=0.05f;
    void reset(float ax,float ay,float az) {q.fromAccel(ax,ay,az);}
    bool update(float gx,float gy,float gz,float ax,float ay,float az,float dt,bool useAccel=true) {
        if (!validStep(gx,gy,gz,dt)) return false;
        float sw=0,sx=0,sy=0,sz=0;
        if(useAccel && unitAccel(ax,ay,az)) {
            // f(q) = predicted gravity - normalized measured acceleration.
            // Gradient J^T f, original IMU-only Madgwick objective.
            float f1=2*(q.x*q.z-q.w*q.y)-ax;
            float f2=2*(q.w*q.x+q.y*q.z)-ay;
            float f3=1-2*(q.x*q.x+q.y*q.y)-az;
            sw=-2*q.y*f1+2*q.x*f2;
            sx=2*q.z*f1+2*q.w*f2-4*q.x*f3;
            sy=-2*q.w*f1+2*q.z*f2-4*q.y*f3;
            sz=2*q.x*f1+2*q.y*f2;
            float n=sqrtf(sw*sw+sx*sx+sy*sy+sz*sz);
            if(n>1e-9f) {float k=beta/n;sw*=k;sx*=k;sy*=k;sz*=k;}
            else sw=sx=sy=sz=0;
        }
        q.integrate(gx,gy,gz,dt,sw,sx,sy,sz); return true;
    }
};

bool calibrate(const BMI088::Sample &s){

    float a[3]={s.ax,s.ay,s.az},g[3]={s.gx,s.gy,s.gz};

BMI08_INTF_RET_TYPE BMI088::busRead(uint8_t reg, uint8_t *data, uint32_t len, void *context) {
    auto *c = static_cast<BusContext *>(context);
    auto &self = *c->owner;
    auto &wire = self._wire;
    if (!data || !len || len > 32)
        return self.busFailure("READ_ARGUMENT", c->address, reg, 255, len, 0);
    wire.beginTransmission(c->address);
    if (wire.write(reg) != 1) {
        wire.endTransmission();
        return self.busFailure("READ_REGISTER_BUFFER", c->address, reg, 255, 1, 0);
    }
    const uint8_t status = wire.endTransmission(false);
    if (status != 0)
        return self.busFailure("READ_REGISTER_TX", c->address, reg, status, len, 0);
    const size_t count = wire.requestFrom(c->address, static_cast<size_t>(len), true);
    if (count != len || wire.available() < static_cast<int>(len)) {
        while (wire.available()) wire.read();
        return self.busFailure("READ_SHORT", c->address, reg, 0, len, count);
    }
    for (uint32_t i = 0; i < len; ++i) data[i] = static_cast<uint8_t>(wire.read());
    return BMI08_INTF_RET_SUCCESS;
}

BMI08_INTF_RET_TYPE BMI088::busWrite(uint8_t reg, const uint8_t *data, uint32_t len, void *context) {
    auto *c = static_cast<BusContext *>(context);
    auto &self = *c->owner;
    auto &wire = self._wire;
    if (!data || !len || len > 31)
        return self.busFailure("WRITE_ARGUMENT", c->address, reg, 255, len, 0);
    wire.beginTransmission(c->address);
    const size_t r = wire.write(reg);
    const size_t n = wire.write(data, static_cast<size_t>(len));
    const uint8_t status = wire.endTransmission(true);
    if (r != 1 || n != len)
        return self.busFailure("WRITE_BUFFER", c->address, reg, 255, len, n);
    if (status != 0)
        return self.busFailure("WRITE_TX", c->address, reg, status, len, n);
    return BMI08_INTF_RET_SUCCESS;
}

bool BMI088::beginSync(SyncRate rate, Stream *startupLog, bool resetGyro) {
    _ready = false;
    if (rate != SyncRate::Hz400 && rate != SyncRate::Hz1000)
        return check(BMI08_E_INVALID_INPUT, "unsupported I2C sync rate");
    if (!isConnection()) return false;
    if (startupLog) startupLog->println("IDs OK: ACC=0x1E GYR=0x0F");
    uint8_t originalConf, originalCtrl;
    // Probe Accel before the optional gyro reset to locate any loss of access.
    if (!readRegister(false, BMI08_REG_ACCEL_PWR_CONF, originalConf))
        return check(_error, "accel baseline PWR_CONF (before gyro step)");
    if (!readRegister(false, BMI08_REG_ACCEL_PWR_CTRL, originalCtrl))
        return check(_error, "accel baseline PWR_CTRL (before gyro step)");
    if (startupLog) {
        startupLog->print("ACC baseline: PWR_CONF=0x"); startupLog->print(originalConf, HEX);
        startupLog->print(" PWR_CTRL=0x"); startupLog->println(originalCtrl, HEX);
    }
    if (resetGyro) {
        if (startupLog) startupLog->println("GYR reset: ENABLED (diagnostic A/B)");
        const int8_t result = bmi08g_soft_reset(&_dev);
        // On error the Bosch API does not wait; still allow reset to settle.
        if (result != BMI08_OK) delay(30);
        if (!check(result, "gyro reset")) return false;
        if (!readRegister(false, BMI08_REG_ACCEL_PWR_CONF, originalConf))
            return check(_error, "accel PWR_CONF immediately after gyro reset");
        if (startupLog) startupLog->println("ACC access after GYR reset: OK");
    } else if (startupLog) {
        startupLog->println("GYR reset: SKIPPED (Crazyflie-style startup)");
    }
    // No reset does NOT mean no configuration. Later stages explicitly set
    // gyro normal mode, range, ODR/BW, and INT3/INT4 routing, then read back.
    // BMI088 datasheet rev1.9 section 4.8.1: active-mode soft reset can
    // release SDA during ACK. Prepare APS + disabled sensor BEFORE reset.
    // Use documented full-byte values (0x7C=0x03, 0x7D=0x00), not 0x7C=1.
    // Bosch API waits 5ms between writes and 5ms after the power transition.
    _dev.accel_cfg.power = BMI08_ACCEL_PM_SUSPEND;
    if (!check(bmi08a_set_power_mode(&_dev), "accel pre-reset suspend")) return false;
    uint8_t pwrConf, pwrCtrl;
    if (!readRegister(false, BMI08_REG_ACCEL_PWR_CONF, pwrConf) ||
        !readRegister(false, BMI08_REG_ACCEL_PWR_CTRL, pwrCtrl)) return false;
    if (startupLog) {
        startupLog->print("ACC pre-reset: PWR_CONF=0x"); startupLog->print(pwrConf, HEX);
        startupLog->print(" PWR_CTRL=0x"); startupLog->println(pwrCtrl, HEX);
    }
    if (pwrConf != 0x03 || pwrCtrl != 0x00)
        return check(BMI08_E_INVALID_CONFIG, "accel pre-reset power readback");
    const int8_t resetResult = bmi08a_soft_reset(&_dev);
    // Wait even if the transaction failed; do not access a possibly resetting die.
    delay(5);
    if (!check(resetResult, "accel reset after suspend")) return false;
    if (startupLog) startupLog->println("ACC reset ACK OK");
    if (!isConnection()) return false;
    if (!readRegister(false, BMI08_REG_ACCEL_PWR_CONF, pwrConf) ||
        !readRegister(false, BMI08_REG_ACCEL_PWR_CTRL, pwrCtrl)) return false;
    if (pwrConf != 0x03 || pwrCtrl != 0x00)
        return check(BMI08_E_INVALID_CONFIG, "accel post-reset power readback");
    if (startupLog) startupLog->println("Post-reset IDs OK; loading sync config...");
    // Includes configuration stream upload, startup delay and INTERNAL_STATUS check.
    const uint32_t errorsBeforeUpload = _i2cErrors;
    if (!check(bmi08a_load_config_file(&_dev), "load Bosch sync config")) return false;
    // Upstream upload loop may overwrite an earlier chunk error with a later OK.
    if (_i2cErrors != errorsBeforeUpload)
        return check(BMI08_E_COM_FAIL, "sync config chunk transfer");
    _dev.accel_cfg.power = BMI08_ACCEL_PM_ACTIVE;
    if (!check(bmi08a_set_power_mode(&_dev), "accel active")) return false;
    _dev.gyro_cfg.power = BMI08_GYRO_PM_NORMAL;
    if (!check(bmi08g_set_power_mode(&_dev), "gyro normal")) return false;
    _dev.accel_cfg.range = BMI088_ACCEL_RANGE_6G;
    _dev.gyro_cfg.range = BMI08_GYRO_RANGE_2000_DPS;
    bmi08_data_sync_cfg sync{};
    sync.mode = rate == SyncRate::Hz400 ? BMI08_ACCEL_DATA_SYNC_MODE_400HZ
                                      : BMI08_ACCEL_DATA_SYNC_MODE_1000HZ;
    if (!check(bmi08xa_configure_data_synchronization(sync, &_dev), "sync mode")) return false;

    bmi08_int_cfg irq{};
    // Configure INT2 as input FIRST. INT2 and INT3 are physically connected.
    auto &input = irq.accel_int_config_1;
    input.int_channel = BMI08_INT_CHANNEL_2;
    input.int_type = BMI08_ACCEL_SYNC_INPUT;
    input.int_pin_cfg.output_mode = BMI08_INT_MODE_PUSH_PULL;
    input.int_pin_cfg.lvl = BMI08_INT_ACTIVE_HIGH;
    input.int_pin_cfg.enable_int_pin = BMI08_ENABLE;
    // INT1 is synchronized DRDY, not the ordinary accelerometer DRDY.
    auto &output = irq.accel_int_config_2;
    output.int_channel = BMI08_INT_CHANNEL_1;
    output.int_type = BMI08_ACCEL_INT_SYNC_DATA_RDY;
    output.int_pin_cfg.output_mode = BMI08_INT_MODE_PUSH_PULL;
    output.int_pin_cfg.lvl = BMI08_INT_ACTIVE_HIGH;
    output.int_pin_cfg.enable_int_pin = BMI08_ENABLE;
    auto &g3 = irq.gyro_int_config_1;
    g3.int_channel = BMI08_INT_CHANNEL_3;
    g3.int_type = BMI08_GYRO_INT_DATA_RDY;
    g3.int_pin_cfg.output_mode = BMI08_INT_MODE_PUSH_PULL;
    g3.int_pin_cfg.lvl = BMI08_INT_ACTIVE_HIGH;
    g3.int_pin_cfg.enable_int_pin = BMI08_ENABLE;
    auto &g4 = irq.gyro_int_config_2;
    g4 = g3;
    g4.int_channel = BMI08_INT_CHANNEL_4;
    g4.int_pin_cfg.enable_int_pin = BMI08_DISABLE;
    if (!check(bmi08a_set_data_sync_int_config(&irq, &_dev), "interrupt routing")) return false;

    // Validate the critical directions, mappings and ranges before reporting ready.
    struct Check { bool gyro; uint8_t reg, mask, expected; };
    const Check checks[] = {
        {false, 0x54, 0x1F, 0x13}, // INT2 edge input, output disabled
        {false, 0x53, 0x1E, 0x0A}, // INT1 active-high push-pull output
        {false, 0x56, 0x01, 0x01}, // sync DRDY -> INT1
        {false, 0x58, 0x44, 0x00}, // ordinary accel DRDY unmapped
        {false, 0x41, 0x03, 0x01}, // +/-6g
        {true,  0x0F, 0x07, 0x00}, // +/-2000dps
        {true,  0x15, 0x80, 0x80}, // gyro DRDY enabled
        {true,  0x16, 0x03, 0x01}, // INT3 active-high push-pull
        {true,  0x18, 0x81, 0x01}  // gyro DRDY -> INT3 only
    };
    for (const auto &c : checks) {
        uint8_t value;
        if (!readRegister(c.gyro, c.reg, value)) return false;
        if ((value & c.mask) != c.expected)
            return check(BMI08_E_INVALID_CONFIG, "interrupt/range readback");
    }
    _ready = true;
    return check(BMI08_OK, "ready");
}

bool BMI088::readSynchronized(Sample &out) {
    if (!_ready) return check(BMI08_E_INVALID_CONFIG, "not initialized");
    bmi08_sensor_data a{}, g{};
    // Bosch reads synced accel XY at 0x1E, Z at 0x27, then gyro at 0x02.
    // Reading normal accel registers 0x12..0x17 would bypass synchronization.
    if (!check(bmi08a_get_synchronized_data(&a, &g, &_dev), "read synchronized")) return false;
    constexpr float accScale = 6.0f * 9.80665f / 32768.0f;
    constexpr float gyrScale = 2000.0f / 32768.0f;
    Sample sample{a.x * accScale, a.y * accScale, a.z * accScale,
                  g.x * gyrScale, g.y * gyrScale, g.z * gyrScale};
    out = sample;
    return true;
}

bool BMI088::readTemperature(float &celsius) {
    int32_t milliC;
    if (!check(bmi08a_get_sensor_temperature(&_dev, &milliC), "temperature")) return false;
    celsius = milliC / 1000.0f;
    return true;
}

bool BMI088::readRegister(bool gyro, uint8_t reg, uint8_t &value) {
    uint8_t v;
    if (busRead(reg, &v, 1, gyro ? static_cast<void *>(&_gyro) : static_cast<void *>(&_acc)) != 0)
        return check(BMI08_E_COM_FAIL, "register read");
    value = v;
    return check(BMI08_OK, "register read");
}

void BMI088::printDiagnostics(Stream &port) {
    const uint8_t accRegs[] = {0x00, 0x02, 0x2A, 0x40, 0x41, 0x53, 0x54, 0x56, 0x57, 0x58, 0x7C, 0x7D};
    const uint8_t gyrRegs[] = {0x00, 0x0F, 0x10, 0x11, 0x15, 0x16, 0x18};
    for (unsigned die = 0; die < 2; ++die) {
        const uint8_t *regs = die ? gyrRegs : accRegs;
        const unsigned count = die ? sizeof(gyrRegs) : sizeof(accRegs);
        for (unsigned i = 0; i < count; ++i) {
            uint8_t value;
            port.print(die ? "GYR 0x" : "ACC 0x"); port.print(regs[i], HEX);
            if (readRegister(die, regs[i], value)) { port.print(" = 0x"); port.println(value, HEX); }
            else port.println(" = READ_FAIL");
        }
    }
}
