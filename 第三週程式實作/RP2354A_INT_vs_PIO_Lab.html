01　學習目標與實驗範圍

本教材以 CURIO RP2354A（RP2350 系列）與 BMI088 為例，研究事件通知、硬體取樣與 CPU 運算之間的分工。完成後應能解釋 State Machine、設計 GPIO INT 與 PIO＋DMA 對照實驗，並正確判讀抖動、遺漏事件和時間量化。

INT 是通知 CPU 的機制；PIO 是可程式化的 I/O 硬體。兩者可以合作，不是互斥選項。Mahony／Madgwick 仍由 CPU 計算。

本份教材是獨立的時序實驗，不修改原 Sensor Fusion 程式。第三個實驗初始化 BMI088 同步模式後，只觀察 INT 接腳；沒有在捕獲期間讀取 I²C，也沒有執行姿態融合。

02　INT：事件發生後，CPU 何時處理？

GPIO 上升沿先使硬體事件狀態成立；中斷控制器在允許且優先權適合時，令 CPU 暫停目前流程、進入中斷處理函式（ISR），然後返回主程式。ISR 內取得的時間是「CPU 服務事件的時間」，通常晚於實際邊緣。

若真實事件時間為 tₖ，ISR 時間為 uₖ = tₖ + Lₖ，則量到的週期為 uₖ−uₖ₋₁ = Tₖ + Lₖ−Lₖ₋₁。固定延遲會抵消，變動延遲會形成週期抖動。

CPU 正在一般計算，並不等於中斷被阻擋。只有遮蔽中斷、較高優先權工作或其他實際阻塞來源，才應被具體歸因。GPIO 事件狀態不是無限佇列：遮蔽期間多次相同邊緣可能合併，恢復中斷也無法重建全部歷史。

03　PIO State Machine 的構成

State Machine（狀態機）按照程式計數器 PC 執行短小的 PIO 指令，使用自己的時脈分頻器操作接腳、移位與等待條件，不需要 CPU 為每個取樣點執行指令。RP2350 有三組 PIO，每組四個狀態機；同組狀態機共用指令記憶體。

元件功能與本實驗用途
PC／指令記憶體決定下一條指令；本例共用五條指令。
X、Y32-bit 暫存器；X 計數剩餘取樣。
ISR、OSRInput／Output Shift Register；此處 ISR 指輸入移位暫存器，不是中斷服務函式。
RX／TX FIFO與 CPU／DMA 交換資料；本例 RX 接收打包的取樣，TX 傳入取樣次數。
分頻器設定狀態機執行速度；等待、FIFO 停滯仍可能使指令無法如期前進。
IRQ flagsPIO 內部旗標；是否進一步中斷 CPU，須另行設定中斷來源與 NVIC。

05　資料路徑與五條 PIO 指令

GPIO 上升沿 → GPIO IRQ → CPU ISR → 時間陣列
GPIO 電位 → PIO IN → RX FIFO → DMA → RAM → 邊緣解碼
pull block       ; CPU 將 N−1 放進 TX FIFO，取出至 OSR
mov x, osr       ; X = N−1
sample:
    in pins, 2   ; 同一取樣點讀取兩個相鄰 GPIO
    jmp x-- sample
irq wait 0       ; 設定旗標 0 並等待清除，停止本次捕獲

IN 與 JMP 各佔一個狀態機週期。X 從 N−1 倒數，使 IN 執行 N 次。最後的 IRQ WAIT 是完成旗標，本例由 CPU 輪詢，沒有啟用 PIO 的 CPU 中斷。CPU 確認旗標及 DMA 完成後停用狀態機，下次捕獲重新初始化。

若只用 DMA 固定長度、卻讓 PIO 永遠取樣，DMA 完成後 RX FIFO 會塞滿，造成 RXSTALL，容易誤判捕獲過程。本例同時限制 PIO 取樣總數，避免這種尾端停滯。

06　取樣時序、資料打包與容量

fSM = fsys/D；fs = fsys/(2D)。本例 fsys=150 MHz、D=75，所以 fSM=2 MHz、fs=1 MHz，取樣間隔 1 µs。

每次 IN 讀 2 bit，右移並在累積 32 bit 時自動推入 RX FIFO：每個 word 有 16 個取樣。最早的取樣位於最低兩個 bit。4096 words × 4 bytes = 16384 bytes；4096 × 16 = 65536 個取樣，捕獲長度為 65.536 ms。DMA 平均流量 250000 bytes/s。

1 MHz 是數位接腳取樣率，不是 BMI088 的 IMU ODR，也不是 Sensor Fusion 更新率。

此計算器只用於概念探索；提供的程式固定 1 MHz，且檢查系統時脈是否可整數分頻。欲改成任意取樣率，須一併檢查 DMA 長度、時間窗與統計設定。

09　實驗一：GPIO INT 基準

目的：先確認 CPU 計算與中斷遮蔽是不同現象。燒錄 Lab01_INT，完成 GPIO2→6、7 接線。硬體 PWM 產生 1 kHz、50% duty 訊號，不依賴 loop() 逐次翻轉 GPIO。

  1. 送 n，正常捕獲一次，記錄兩通道 mean/min/max/sd。
  2. 送 b，主迴圈重複忙等 40 µs，但 IRQ 維持開啟。
  3. 送 m，刻意每隔約 7 ms 遮蔽 Core0 IRQ 1200 µs，觀察週期分散與事件數。
  4. 每種情境至少做 20 次；r 重複目前模式，d 匯出最後一窗所有事件。

1200 µs 遮蔽超過 1 kHz 的 1000 µs 週期，但是否每一次都漏邊緣仍取決於相位；不要要求每窗固定漏幾筆。兩通道雖收到相同邊緣，GPIO 回呼依序執行，ISR 時間不一定相同。

10　實驗二：同時比較 INT 與 PIO＋DMA

目的：對同一個訊號同時留下兩種紀錄。保持實驗一接線，改燒錄 Lab02_PIO_INT。依序 n、b、m，各重複至少 20 次。

  1. 先檢查 CAPTURE 的 valid=1、timeout=0、rxstall=0、dma_error=0、remaining=0。
  2. 所有 INT_OVERFLOW 與 PIO_EDGE_OVERFLOW 必須為 0；溢位資料不納入比較。
  3. 比較 INT／PIO 兩通道的週期平均與標準差，並記錄有效窗內事件數。
  4. 送 d 保存 TRACE。將各來源、各通道分開畫 tₖ 與 Δtₖ；不要跨不同捕獲窗連接時間軸。

預期 PIO 在 m 模式仍保留硬體取樣時序；INT 可能出現長週期及隨後短週期，或事件數下降。這是預期趨勢，並非本教材已取得的實測結果。

合成 PWM 與 PIO 使用同一系統時脈，整數週期可能量到零抖動；這不能證明真實時鐘誤差為零。要研究絕對頻率誤差，需獨立、已知精度的訊號源。

11　實驗三：BMI088 INT1／INT3 時序

目的：觀察真實感測器的兩路事件。移除合成訊號跳線，使用 BMI088 接線，燒錄 Lab03_BMI088_PIO_INT。驅動呼叫 beginSync(Hz1000, &Serial, false)，延續跳過 Gyro soft reset 的已成功啟動方式。

  1. 確認初始化成功；失敗時保存完整 I²C 錯誤，不繼續解讀事件統計。
  2. 通道 0 是 GPIO22／INT1；通道 1 是 GPIO23／INT3。
  3. 先 n 觀察兩路實際事件週期，再 b、m，比較軟體服務時序與 PIO 觀察結果。
  4. 記錄 PHASE_A_AFTER_PREV_G；它表示每個 A 邊緣距離「前一個或同時的 G 邊緣」多久。
PHASE 只是電氣事件相位，不等同感測器的物理量測延遲、濾波群延遲或融合中正確的 A/G 配對。若漏事件，不能用同一索引強行配對兩列資料。

1000 Hz 同步輸出需要 Bosch 同步設定檔與配套的 ODR／BW／INT 設定，不能只把 delay 改成 1 ms。封裝保留既有驅動與 Bosch 檔案；實驗沒有宣稱加速度計獨立原生取樣率已變成 1000 Hz。

12　如何判讀統計與 CSV

輸出意義
META模式、訊號來源、PIO 取樣率、捕獲窗與遮蔽次數。
STATsource, channel, edges_in_guard, intervals, mean_us, min_us, max_us, sd_us。
edges_in_guard排除前後各 2000 µs 後保留的事件數；不是前後邊界內的事件。
sd_us週期間隔的樣本標準差：√[Σ(Tᵢ−平均T)²/(M−1)]。
TRACEsource, channel, index, t_us；PIO 時間從取樣索引換算。
OVERFLOW事件陣列容量 512；超出即使 CAPTURE valid=1，該事件統計仍不可用。

PIO 時間基準是第一個取樣點，INT 基準是 CPU 啟動捕獲時讀取的系統計時器，兩者有未知起始偏移。因此不能直接算 INT.t−PIO.t 當作精確 ISR latency。排除前後 2 ms 能降低邊界影響，但不能保證兩來源統計邊界永遠對齊；單窗相差一個事件不宜直接判定漏接。

建議結果表欄位：實驗、模式、重複序號、valid、來源、通道、事件數、週期平均、最小、最大、SD、overflow、備註。保留原始紀錄，並將期望趨勢與實測數值分開。

13　連回 Sensor Fusion 的架構

實務上的 CPU 流程可採「短 ISR 記錄事件與序號 → 主迴圈讀取 I²C → 驗證成功與新鮮度 → 單位轉換／校正 → Mahony 或 Madgwick → 降頻輸出 Serial Plotter」。ISR 內不做 Wire 交易、Serial 列印或融合運算。

PIO 能協助調查事件是否穩定、CPU 是否延遲，也可實作特定通訊；但不會讓標準 I²C 感測器自動超過其規格速率。BMI088 的 I²C 通訊與同步資料讀取成本仍要納入 1 ms 預算。DMA 搬 GPIO 取樣也不等於 DMA 已搬到感測器 XYZ 數據。

融合使用的 Δt 應代表接受樣本的有效間隔，不能把每次 loop 耗時或 PIO 的 1 µs 當成 IMU Δt。I²C 失敗、資料過期、漏樣應被明確標記，不能無條件重用凍結值積分。六軸 IMU 沒有絕對航向參考，Yaw 長時間漂移不是 PIO 可以修正的問題。

14　誤差來源與實驗限制

  • 時間量化：1 µs 取樣網格限制邊緣解析度；小於一個取樣間隔的脈衝可能完全落在兩次取樣之間。
  • 同步器：GPIO 輸入同步器引入延遲；本實驗未略過同步器，也未校正其絕對延遲。
  • 資源競爭：PIO 不依賴 CPU ISR，但仍依赖時脈、FIFO、DMA、匯流排與 RAM；發生 RXSTALL 時均勻時間軸已不成立。
  • volatile：它避免某些編譯最佳化，不等於鎖。本例採同一核心 ISR／主程式，記錄停止後才複製陣列，且在短臨界區切換記錄狀態。
  • 程式位置：自訂記錄函式標記為 SRAM 執行，但 Arduino GPIO dispatcher 與所有系統路徑並未因此全部保證位於 SRAM；不能宣稱完整 ISR 路徑無 Flash 延遲。
  • 短窗：65.536 ms 適合展示機制，不足以證明長期可靠性；需要長期量測時另設計連續 DMA 緩衝與資料消費速率監測。

討論題與參考答案
  1. CPU 很忙一定漏中斷嗎？不一定；先確認 IRQ 是否允許、優先權與服務成本。
  2. PIO 能直接計算 Mahony 嗎？本平台應由 CPU 做浮點融合，PIO 專注 I/O。
  3. PIO 週期 SD=0 能證明晶振精準嗎？不能，尤其同源時脈測試。
  4. CAPTURE valid=1 就可使用所有統計嗎？還需檢查事件陣列 overflow、來源與訊號條件。
  5. 如何精測 ISR latency？加入具有共同時間基準的硬體事件標記／ISR 探針，評估探針本身開銷，不能直接相減目前兩個基準。

    uint32_t n=irqN[ch];
    if(n<EDGE_CAP){irqEdges[ch][n]=t;irqN[ch]=n+1;}else ++irqOverflow[ch];
}
void __not_in_flash_func(onA)(){recordEdge(0);}
void __not_in_flash_func(onG)(){recordEdge(1);}
void fatal(const char *msg){Serial.println(msg);while(true)delay(1000);}
void initSampler(){
#if ENABLE_PIO
    captureSm=pio_claim_unused_sm(capturePio,false);
    if(captureSm<0||!pio_can_add_program(capturePio,&samplerProgram))fatal("PIO resource unavailable");
    programOffset=pio_add_program(capturePio,&samplerProgram);
    dmaCh=dma_claim_unused_channel(false);if(dmaCh<0)fatal("DMA resource unavailable");
    // Integer divider: IN + JMP = two state-machine cycles per sample.
    uint32_t sys=clock_get_hz(clk_sys);
    uint32_t div=sys/(2*SAMPLE_HZ);
    if(div<1||div>65535||sys%(2*SAMPLE_HZ))fatal("Choose CPU clock divisible by 2 MHz (150 MHz works)");
    actualSampleHz=float(sys)/(2*div);
    windowUs=uint32_t(double(SAMPLES)*1e6/actualSampleHz);
#else
    actualSampleHz=SAMPLE_HZ;
#endif
}
void prepareSampler(){
#if ENABLE_PIO
    pio_sm_set_enabled(capturePio,captureSm,false);
    pio_interrupt_clear(capturePio,0);
    pio_sm_config c=pio_get_default_sm_config();
    sm_config_set_wrap(&c,programOffset,programOffset+4);
    sm_config_set_in_pins(&c,BASE_PIN);
    sm_config_set_in_shift(&c,true,true,32); // right shift; autopush 32
    sm_config_set_clkdiv(&c,float(clock_get_hz(clk_sys))/(2*SAMPLE_HZ));
    // Keep pins as SIO INPUT: PIO inputs can observe GPIO independently.
    // Do not call pio_gpio_init or configure any PIO output on BMI088 IRQ lines.
    pio_sm_init(capturePio,captureSm,programOffset,&c);
    pio_sm_clear_fifos(capturePio,captureSm);
    pio_sm_put_blocking(capturePio,captureSm,SAMPLES-1);
    capturePio->fdebug=1u<<(PIO_FDEBUG_RXSTALL_LSB+captureSm); // W1C
    dma_channel_config d=dma_channel_get_default_config(dmaCh);
    channel_config_set_transfer_data_size(&d,DMA_SIZE_32);
    channel_config_set_read_increment(&d,false);
    channel_config_set_write_increment(&d,true);
    channel_config_set_dreq(&d,pio_get_dreq(capturePio,captureSm,false));
    dma_channel_configure(dmaCh,&d,packed,&capturePio->rxf[captureSm],WORDS,true);
#endif
}
void exerciseCPU(uint32_t elapsed,uint32_t &nextMask){
    if(mode=='b')busy_wait_us_32(40); // busy, but IRQs remain enabled
    else if(mode=='m'&&elapsed>=nextMask&&elapsed+MASK_US+GUARD_US<windowUs){
        uint32_t s=save_and_disable_interrupts();
        busy_wait_us_32(MASK_US);
        restore_interrupts(s);++maskCount;nextMask=elapsed+MASK_EVERY_US;
    }
}
void captureWindow(){
    recording=false;haveCapture=false;captureValid=false;maskCount=0;
    irqN[0]=irqN[1]=irqOverflow[0]=irqOverflow[1]=0;
    prepareSampler();
    uint32_t saved=save_and_disable_interrupts();
    gpio_acknowledge_irq(BASE_PIN,GPIO_IRQ_EDGE_RISE);
    gpio_acknowledge_irq(BASE_PIN+1,GPIO_IRQ_EDGE_RISE);
    epochUs=time_us_32();recording=true;
#if ENABLE_PIO
    pio_sm_clkdiv_restart(capturePio,captureSm);
    pio_sm_set_enabled(capturePio,captureSm,true);
#endif
    restore_interrupts(saved);
    bool timeout=false;uint32_t nextMask=5000;
    while(true){
        uint32_t elapsed=time_us_32()-epochUs;
#if ENABLE_PIO
        if(pio_interrupt_get(capturePio,0)&&!dma_channel_is_busy(dmaCh))break;
        if(elapsed>windowUs+20000){timeout=true;break;}
#else
        if(elapsed>=windowUs)break;
#endif
        exerciseCPU(elapsed,nextMask);
    }
    saved=save_and_disable_interrupts();recording=false;restore_interrupts(saved);
#if ENABLE_PIO
    pio_sm_set_enabled(capturePio,captureSm,false);
    if(dma_channel_is_busy(dmaCh))dma_channel_abort(dmaCh);
    bool stalled=(capturePio->fdebug&(1u<<(PIO_FDEBUG_RXSTALL_LSB+captureSm)))!=0;
    bool dmaError=(dma_channel_hw_addr(dmaCh)->ctrl_trig&DMA_CH0_CTRL_TRIG_AHB_ERROR_BITS)!=0;
    bool complete=dma_channel_hw_addr(dmaCh)->transfer_count==0;
    captureValid=!timeout&&!stalled&&!dmaError&&complete;
    Serial.printf("CAPTURE,valid=%u,timeout=%u,rxstall=%u,dma_error=%u,remaining=%lu\n",
        captureValid,timeout,stalled,dmaError,(unsigned long)dma_channel_hw_addr(dmaCh)->transfer_count);
    if(captureValid)for(uint32_t c=0;c<2;++c)pioN[c]=extractEdges(packed,SAMPLES,c,pioEdges[c],EDGE_CAP,pioEdgeOverflow[c]);
    else for(uint32_t c=0;c<2;++c){pioN[c]=0;pioEdgeOverflow[c]=false;}
#else
    captureValid=!timeout;
#endif
    for(uint32_t c=0;c<2;++c){storedN[c]=irqN[c];lastIrqOverflow[c]=irqOverflow[c];
        for(uint32_t i=0;i<storedN[c];++i)storedIrq[c][i]=irqEdges[c][i];}
    haveCapture=true;
}
void printStats(const char *kind,uint32_t channel,const uint32_t *edges,uint32_t n,double scale){
    TimingStats s;uint32_t accepted=0;double prev=0;
    for(uint32_t i=0;i<n;++i){double t=edges[i]*scale;
        if(t<GUARD_US||t>=windowUs-GUARD_US)continue;
        if(accepted)s.add(t-prev);prev=t;++accepted;
    }
    if(!s.count)Serial.printf("STAT,%s,%lu,%lu,0,NA,NA,NA,NA\n",kind,(unsigned long)channel,(unsigned long)accepted);
    else Serial.printf("STAT,%s,%lu,%lu,%lu,%.3f,%.3f,%.3f,%.3f\n",kind,(unsigned long)channel,
       (unsigned long)accepted,(unsigned long)s.count,s.mean,s.min,s.max,s.sd());
}
void report(){
    Serial.printf("META,mode=%c,source=%s,fs=%.1f,window_us=%lu,mask_count=%lu\n",mode,
        USE_BMI088?"BMI088":"PWM",actualSampleHz,(unsigned long)windowUs,(unsigned long)maskCount);
    Serial.println("HEADER,source,channel,edges_in_guard,intervals,mean_us,min_us,max_us,sd_us");
    for(uint32_t c=0;c<2;++c){
        printStats("INT",c,storedIrq[c],storedN[c],1.0);
        Serial.printf("INT_OVERFLOW,%lu,%lu\n",(unsigned long)c,(unsigned long)lastIrqOverflow[c]);
#if ENABLE_PIO
        if(captureValid){printStats("PIO",c,pioEdges[c],pioN[c],1e6/actualSampleHz);
            Serial.printf("PIO_EDGE_OVERFLOW,%lu,%u\n",(unsigned long)c,pioEdgeOverflow[c]);}
#endif
    }
#if ENABLE_PIO
    if(captureValid&&!pioEdgeOverflow[0]&&!pioEdgeOverflow[1]){
        TimingStats phase;uint32_t j=0;bool havePrev=false;uint32_t prev=0;
        for(uint32_t i=0;i<pioN[0];++i){uint32_t a=pioEdges[0][i];
            while(j<pioN[1]&&pioEdges[1][j]<=a){prev=pioEdges[1][j++];havePrev=true;}
            double t=a*1e6/actualSampleHz;
            if(havePrev&&t>=GUARD_US&&t<windowUs-GUARD_US)phase.add((a-prev)*1e6/actualSampleHz);
        }
        if(phase.count)Serial.printf("PHASE_A_AFTER_PREV_G,n=%lu,mean_us=%.3f,min_us=%.3f,max_us=%.3f\n",
            (unsigned long)phase.count,phase.mean,phase.min,phase.max);
    }
#endif
    Serial.println("READY: n=normal, b=CPU busy IRQ enabled, m=mask IRQ, r=repeat, d=dump last window");
}
void dump(){
    if(!haveCapture){Serial.println("No capture; send n first");return;}
    Serial.println("TRACE,source,channel,index,t_us");
    for(uint32_t c=0;c<2;++c){
        for(uint32_t i=0;i<storedN[c];++i)Serial.printf("TRACE,INT,%lu,%lu,%lu\n",(unsigned long)c,(unsigned long)i,(unsigned long)storedIrq[c][i]);
#if ENABLE_PIO
        if(captureValid)for(uint32_t i=0;i<pioN[c];++i)Serial.printf("TRACE,PIO,%lu,%lu,%.3f\n",(unsigned long)c,(unsigned long)i,pioEdges[c][i]*1e6/actualSampleHz);
#endif
    }
    Serial.println("END_TRACE");
}

#pragma once
#include <stdint.h>
#include <math.h>
struct TimingStats {
    uint32_t count=0; double mean=0,m2=0,min=0,max=0;
    void add(double v){
        if(!count){min=max=v;} else {if(v<min)min=v;if(v>max)max=v;}
        ++count;double d=v-mean;mean+=d/count;m2+=d*(v-mean);
    }
    double sd() const {return count>1?sqrt(m2/(count-1)):0;}
};
// Shift-right IN 2 + autopush32: oldest pair ends in bits 1:0.
inline uint8_t packedPair(const uint32_t *words,uint32_t sample){
    return uint8_t((words[sample/16] >> (2*(sample%16)))&3u);
}
inline uint32_t extractEdges(const uint32_t *words,uint32_t samples,uint32_t channel,
                            uint32_t *edges,uint32_t capacity,bool &overflow){
    overflow=false;if(!samples)return 0;
    uint32_t n=0;uint8_t prev=(packedPair(words,0)>>channel)&1u;
    for(uint32_t i=1;i<samples;++i){
        uint8_t now=(packedPair(words,i)>>channel)&1u;
        if(now&&!prev){if(n<capacity)edges[n++]=i;else overflow=true;}
        prev=now;
    }
    return n;
}
